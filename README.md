# FakeRO · Roots of Yggdrasil

ต้นแบบเกมออนไลน์ PvE บนเว็บ ภาพไอโซเมตริก2.5D คลิกเดินและโจมตี สร้างด้วย Phaser, TypeScript, Node.js24 และ SQLite ภาพสร้างใหม่ในธีมนอร์ส ไม่มีการใช้ทรัพยากรภาพRagnarok

## เริ่มเล่น

ต้องใช้Node.js24ขึ้นไป แล้วรัน:

```sh
npm ci
npm run build
npm start
```

เปิดพอร์ต3000ของเครื่องที่รันเกม สมัครชื่อบัญชีและรหัสผ่าน แล้วสร้างตัวละครได้1ตัวต่อบัญชี เลือกเผ่า เพศ ทรงผม สีผม และสีตาได้ **ทุกเผ่าเริ่มที่Central** และบันทึกCentralเป็นเมืองเกิด บัญชีจำความคืบหน้า รูปลักษณ์ อาวุธฝึกและสัมภาระ ออกแล้วล็อกอินด้วยบัญชีเดิมได้ Cookieเก็บ30วัน ข้อมูลบันทึกใน`.data/world.sqlite`

ตัวละครเก่าจากเวอร์ชันรหัสกู้คืนยังอยู่: สมัครบัญชีใหม่แล้วใช้ **นำเข้ารหัสกู้คืนตัวละครเดิม** ในหน้าสร้างตัวละคร ผูกได้เฉพาะตัวละครที่ยังไม่มีเจ้าของบัญชี และไม่เปลี่ยนID/ความคืบหน้า ไม่ย้ายตำแหน่งตัวละครเก่าที่มีอยู่แล้ว

ภาพตัวละครเป็น **SDอนิเมะลงสีรุ่น5 แอนิเมชั่นภาพวาดรายเฟรมครบ8ทิศ** ใช้ภาพชุด/ใบหน้าเดียวกันในหน้าสร้าง ภาพโปรไฟล์และแมพ ไม่ใช้ตัวละครทรงเหลี่ยมต้นแบบเดิม รายละเอียดใน [Art direction](docs/ART-DIRECTION.md)

ดู [ท่าโจมตีและคอมโบตามความเร็ว](docs/COMBAT-ANIMATION.md), [หน้ากระเป๋า / มือขวา / Central ใหม่](docs/CHARACTER-INVENTORY-REFINEMENT.md) และ [อัปเดต Central / อาวุธ / มอนสเตอร์](docs/ADVENTURE-UPDATE.md): เดินเร็วขึ้น มีMPจริง จุดพักน้ำพุ NPC Eira อาวุธขาว–ฟ้า96ชิ้น และมอนสเตอร์กระจาย18–28ตัวต่อแมพผจญภัย

รายละเอียด [การถืออาวุธและมุมภาพ](docs/WEAPON-HOLDING.md): เพิ่มท่าธนู/อาวุธสองมือ 768 เฟรม และมุมอาวุธที่เตรียมจากภาพต้นแบบของเกม โดยคงอาวุธขาว–ฟ้าทั้ง 96 ชิ้น

ระบบ [ไอเท็มและกระเป๋า](docs/ITEM-SYSTEM.md): เพิ่มของใช้พื้นฐาน อุปกรณ์สวมใส่ 4 ช่อง ร้านเสบียง น้ำหนัก ไอเท็มบนพื้น 30 นาที และชุดเดินทางฟรีจาก Eira

[Central ผังใหม่](docs/CENTRAL-REBUILD.md): ลานเกิดวงกลมและหอนาฬิกา เขตฟื้น HP/MP ทั้งลาน ตลาด 24 แผง สภา ลานฝึก ย่านบ้านเรือน สวน และประตูอิกดราซิล พร้อมประตูเมืองสองทาง

## วิธีเล่น

- คลิกพื้นเดิน คลิกมอนสเตอร์โจมตีต่อเนื่อง หรือกด1เพื่อเลือกมอนสเตอร์ใกล้ที่สุด
- 2เลือกกายภาพ,3เลือกเวท,4หยุด ไม่ล้างคูลดาวน์เมื่อสลับอาวุธ
- Cสเตตัส,Bกระเป๋า,Mแผนที่โลก,Nสารานุกรม และEscปิดหน้าต่าง
- เปิดคลังอาวุธ96รายการจากปุ่มอาวุธด้านล่าง สวมของในกระเป๋าด้วยB; ตัวเลือกอาวุธฝึก17แบบสำหรับGM ช่องสกิลอาชีพที่ล็อกไว้ยังไม่เปิดใช้
- เดินผ่านประตูไป35แมพ คลิกสิ่งก่อสร้างเพื่อเดินไปใช้บริการ ตั้งเมืองเกิดที่โรงเตี๊ยม ใช้NPCวาร์ปไปพื้นที่ที่ค้นพบแล้ว
- มีมอนสเตอร์118สายพันธุ์ครบเลเวล3–120 ไม่เกิดในเมือง ภาพใช้24รูปร่างพื้นฐานร่วมกับสี/ขนาด/รายละเอียดตามภูมิภาค บอสแมพ6,Root Warden1,World Boss6
- สารานุกรมแสดงภาพเคลื่อนไหวหน้า/หลังทั้งมอนสเตอร์และบอส โดยไม่ต้องใช้ไฟล์แนบในแชต

## บัญชีGMสำหรับเจ้าของเกม

```sh
npm run gm:create -- --username worldkeeper
```

สคริปต์สร้างรหัสสุ่มและเก็บใน **`.data/gm-credentials.txt`** ซึ่งไม่รวมในGit ใช้ช่องล็อกอินเดียวกับผู้เล่น จากนั้นสร้างตัวละครแล้วเปิด **เครื่องมือGMใต้โปรไฟล์** เพื่อวาร์ปไปทุกแมพ ฟื้นHP/MP หรือตั้งเลเวล1–120และรีเซ็ตแต้มเพื่อทดลองสาย ปุ่มแต่งตัวละครข้างกันกลับไปแก้รูปลักษณ์ตัวเดิมได้โดยไม่สร้างตัวใหม่ ภายในเครื่องมือGMมีหน้าตรวจชิ้นส่วนตัวละคร หมุน8ทิศ แยกหัว/ผม/ชุดเต็มตัว และเล่นท่าต่างๆโดยไม่บันทึกการเปลี่ยนแปลง

เปลี่ยนรหัสGMที่มีอยู่ด้วย `npm run gm:create -- --username worldkeeper --reset` จะยกเลิกsessionบัญชีGMเดิม หรือกำหนด`GM_USERNAME`และ`GM_PASSWORD`ผ่านenvironmentสำหรับสร้างGMครั้งแรกบนเซิร์ฟเวอร์ใหม่ ระบบไม่ฝังรหัสเจ้าของไว้ในsource/client และไม่เปลี่ยนรหัสบัญชีที่มีอยู่ทุกครั้งที่รีสตาร์ต

## ทดสอบบนเว็บและโฮสต์

เกมต้องมีNode.js/WebSocketและฐานข้อมูลถาวร **pushขึ้นGitHubอย่างเดียวไม่ทำให้มีเว็บออนไลน์** GitHubPagesใช้กับbackendชุดนี้ไม่ได้

แนะนำVMที่อยู่ในโควตาOracleCloudAlwaysFreeสำหรับการทดสอบกลุ่มเล็ก หากสมัครได้และมีเครื่องฟรีว่าง เตรียมDocker,volumeฐานข้อมูลและHTTPS proxyแล้ว ดู [คู่มือติดตั้ง](docs/HOSTING.md) Renderฟรีเหมาะทดลองชั่วคราว แต่ต้องเปลี่ยนไปใช้ฐานข้อมูลภายนอกก่อนเก็บความคืบหน้าระยะยาว เพราะไฟล์บนinstanceไม่ถาวร

```sh
cp .env.example .env
# ตั้ง GM_PASSWORD ที่แข็งแรงใน .env ก่อน
# เมื่อติดตั้งออนไลน์ ให้ตั้ง PUBLIC_ORIGIN ตรงกับ URL จริง
docker compose up -d --build
```

Dockerใช้volume`world-data`เก็บฐานข้อมูลข้ามการสร้างcontainerใหม่ อย่าใช้`docker compose down -v`หากต้องการรักษาข้อมูล เริ่มต้นเปิดเฉพาะloopback ถ้าใช้domainและHTTPSให้อ่านคู่มือก่อนเปิดรับผู้ทดสอบภายนอก

ค่าตั้งหลัก: `HOST`(ค่าเริ่มต้น127.0.0.1),`PORT`(3000),`DB_PATH`(.data/world.sqlite),`PUBLIC_ORIGIN`(URLจริงรวมscheme/port),`GM_USERNAME`,`GM_PASSWORD` คัดลอก`.env`สำหรับDockerCompose; การรัน`npm start`ตรงๆใช้environmentของprocess ไม่มีการโหลด`.env`อัตโนมัติ

## ตรวจสอบและพัฒนา

```sh
npm test
npm run build
npm run test:accounts
npm run test:hud
npm run test:adventure
```

Browser testsใช้Chromium (`CHROMIUM_PATH=/usr/bin/chromium` หรือใช้Playwright browserที่ติดตั้งไว้) ทดสอบบัญชี/HUDในฐานข้อมูลแยก ส่วน `test:world` และ `test:appearance` ต้องเปิดserverทดสอบด้วยDBแยกก่อน มีGitHubActionsตรวจunit/integrationและbuildทุกครั้งที่pushmain ไม่ได้deployไปโฮสต์อัตโนมัติ
