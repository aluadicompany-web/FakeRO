# รูปแบบโลก เมือง สิ่งก่อสร้าง และเขตบอส · ข้อเสนอร่างแรก

> อัปเดต: พื้นที่ตามผังถูกสร้างเป็นruntime35แมพแล้ว (34ภายนอก+ห้องทดสอบMain Questแรก) ดู [RUNTIME.md](RUNTIME.md) สำหรับสิ่งที่เล่นได้จริงและส่วนบริการที่ยังไม่ครบ เนื้อหาด้านล่างเก็บข้อเสนอผังต้นฉบับ

Centralและเผ่าทั้ง6เป็นโครงที่ยืนยันแล้ว ส่วนชื่อเมืองเผ่า บอส ชื่อแมพ ทิศทาง และจำนวนแมพในเอกสารนี้เป็น **ข้อเสนอใหม่** ยังไม่เพิ่มแมพจริงหรือประกาศว่าเนื้อหาทั้งหมดผลิตเสร็จ

## รูปแบบโลก

ใช้โลกเชื่อมต่อเป็นโซนแบบRO ภาพไอโซเมตริก2.5D สไปรต์บนฉากอนิเมะสีสด แสงแดดอุ่นและเงาเย็นแยกชัด เมืองหลวงอยู่กลาง มีถนนหลัก6สายและถนนวงแหวนผ่านทางแยกนอกเมืองเผ่า ไม่บังคับผู้เล่นเดินเข้าเมืองต่างเผ่าเพื่อเดินทางข้ามโลก

ภูมิภาคมีธีมตามเผ่าแต่ **กฎเจ้าถิ่นใช้เฉพาะแมพในเขตเมือง** ไม่ขยายไปทั้งป่า/ภูเขาหรือเขตบอส เผ่าไม่ได้ผูกสิทธิ์เก็บทรัพยากรหรือฆ่าบอสในภูมิภาคนั้นโดยอัตโนมัติ ทุกเผ่าเดินทางได้ตามกฎเดียวกัน

[ภาพแนวทางโลก](art/world-concept.png) เป็นภาพconceptให้เห็นบรรยากาศและตำแหน่งหลัก ไม่ใช่navigation meshหรือแผนที่ที่scale/ประตูตรงทุกพิกเซล ใช้ `world-layout.json` เป็นข้อมูลอ้างอิงการเชื่อมและกฎเขต

## 1. Central — เมืองหลวงร่วม

[เปิดผังหน้าที่อาคาร Central](art/central-functional.svg)

เป็นพื้นที่ปลอดภัยจากPvPทั้งหมด หอผนึกรากโลกอยู่ใจกลางเมืองจริง ไม่แยกไปอยู่นอกเมือง การห้ามPvPไม่หมายถึงห้องบอสPvEด้านในไม่มีอันตราย

ผังเมืองเสนอเป็น6ย่านรอบวงลานหอ มีช่องทางเดินไม่ให้ร้านบังทางเข้าMain Quest ตลาดกับโรงช่างอยู่ใกล้กัน คลัง/เสบียงเข้าถึงได้ก่อนเข้าหอ วาร์ปและโรงเตี๊ยมอยู่ขอบลาน ไม่ซ้อนตำแหน่งเกิดกับประตูบอส

| สิ่งก่อสร้าง | หน้าที่ |
|---|---|
| หอผนึกรากโลก | จุดศูนย์กลางเมือง ห้องรอ/ทางเข้าMain Quest รากอิกดราซิลคลุมอาคาร |
| ตลาด Silfr | ร้านเช่าและพื้นที่พ่อค้า รวมประกาศสินค้ากับบริการช่าง |
| ลานเตาหลอม | พื้นที่ช่างผู้เล่นเปิดบริการและสถานีผลิต ไม่ให้NPCแทนผู้สร้างของแดง |
| คลังกลาง | จุดบริการฝากของ รูปแบบคลังส่วนตัว/บัญชียังรอกำหนด |
| ลานวาร์ป | NPCไปจุดที่ตัวละครเคยค้นพบแล้ว ไม่ปลดล็อกเมืองฟรีทุกแห่ง |
| โรงเตี๊ยมและจุดบันทึก | จุดพักและตั้งเมืองเกิดตามระบบที่จะกำหนด |
| ร้านเสบียง | ยาพื้นฐานและเครื่องมือ ซื้อขายด้วยSilfrตามกฎราคา |
| ลานรวมปาร์ตี้ | กระดานประกาศหาเพื่อน/เตรียมMain Quest ไม่ใช่ระบบกิลด์ใหม่ |
| หอสภาหกเผ่า | แสดงเหตุการณ์เผ่าและความคืบหน้าทั้งserver ยังไม่กำหนดอำนาจปกครองใหม่ |
| ตรอกฝึกอาชีพ | ทางเข้าถึงการฝึกอาวุธ/รวบรวม/ผลิตพื้นฐานสำหรับทุกเผ่า |
| ครัวและลานเตรียมเสบียง | สถานีทำอาหารและจุดเรียนรู้อาชีพ |
| ท่าและบึงพักเมือง | จุดตกปลาฝึกหัดและพื้นที่สังคม ไม่สร้างบ้านหรือสัตว์ขี่ในรอบนี้ |

ผู้มาเยือนไม่ต้องเข้าเมืองเผ่าอื่นเพื่อฝึกอาวุธหลักหรือใช้บริการจำเป็น Centralมีทางเข้าถึงพื้นฐานร่วมทั้งหมด เมืองเผ่าเน้นวัฒนธรรม/เควสและฐานรวมตัว ไม่สร้างrace lockของงานช่างหรืออาวุธโดยอ้อม

## 2. เมืองเผ่าและสภาพแวดล้อม

ทุกเมืองมีประตู/กำแพงระบุขอบเขตชัด เสนออาคารพื้นฐานร่วม: หอเผ่า,จุดบันทึกเกิด,ร้านเสบียง,คลัง,ลานNPCวาร์ป,ลานฝึก/บริการช่าง และประตูสู่พื้นที่นอกเมือง

ภายในทุกอาคารและย่านที่ยังอยู่ในแมพเมือง ใช้กฎเมืองเผ่าเดิม: เจ้าถิ่นโจมตีต่างเผ่าได้ฝ่ายเดียว ผู้มาเยือนตอบโต้ไม่ได้ ไม่เพิ่มข้อยกเว้นปลอดภัยในตลาด/วิหาร/คลังโดยไม่ได้ตกลง ขอบประตูเมืองแสดงชื่อเจ้าถิ่นและความเสี่ยงก่อนข้าม

| เมืองเสนอ | เผ่า / ทิศ | สภาพแวดล้อมและอาคาร |
|---|---|---|
| Emberheim / เอมเบอร์ไฮม์ | muspel / ใต้ | กำแพงหินดำ หลังคาแดง รางระบายไอร้อน; ลานฝึกบนหินบะซอลต์, อาคารสภาเปลวเพลิง |
| Ljosgard / ลยอสการ์ด | alf / ตะวันตกเฉียงเหนือ | บ้านไม้สว่างเชื่อมระเบียง หลังคาเขียว โคนไม้ใหญ่; เรือนสังเกตป่า, เรือนเพาะสมุนไพร |
| Eirfjord / เอียร์ฟยอร์ด | jotun / เหนือ | หินขาว หลังคาฟ้า ทางน้ำอุ่น ธีมผู้เยียวยาไม่ใช่ป้อมเกราะหนัก; วิหารธารชีวิต, หอจารึกการเยียวยา |
| Vanaholt / วานาโฮลต์ | vanir / ตะวันออกเฉียงเหนือ | หินม่วงอ่อน ไม้สว่าง วงรูนและระเบียงเปิด; หอศึกษารูน, หอดูดาวประจำเมือง |
| Aurvik / ออร์วิก | nid / ตะวันออกเฉียงใต้ | อาคารหินกับไม้ หลังคาโอเคอร์ เครนและรางแร่ขนาดเล็ก; โรงช่างรูน, ท่าขนส่งแร่ |
| Skuggahav / สกุกกาฮาฟ | skug / ตะวันตกเฉียงใต้ | ไม้ดำ หลังคาถ่าน สะพานทางเดิน โคมสีอุ่น ยังคงอ่านทางได้ชัด; หอเฝ้าหมอก, ท่าเรือสะพานดำ |

## 3. ชั้นของแมพในแต่ละภูมิภาค

| โซน | บทบาท | กฎPvP |
|---|---|---|
| City | เมืองเกิด/เควสเผ่า/บริการ | เจ้าถิ่นโจมตีผู้มาเยือนได้ฝ่ายเดียว |
| Field 1 | ทางออกเมือง จุดฝึกต้น ทรัพยากรเริ่มต้น ทางแยกถนนวงแหวน | ห้ามPvP |
| Field 2 | แหล่งล่า/รวบรวมหลัก ซากสิ่งก่อสร้าง ทางแยกเข้าบอส | ห้ามPvP |
| Field 3 | พื้นที่ลึกสำหรับเนื้อหาระดับสูง มีที่ว่างแยกแขนงตามช่วงคลาสภายหลัง | ห้ามPvP |
| Boss Arena | แมพกิ่งแยก ปลายทางบอส ไม่ขวางถนนหลัก | ห้ามPvPในข้อเสนอชุดแรก |

Field1เหมาะกับเนื้อหาเริ่มต้น,Field2ช่วงกลาง,Field3ช่วงสูง แต่ยังไม่ล็อกระดับมอนสเตอร์/จำนวนผู้เล่น/ค่าEXP พื้นที่ระดับ70–100ต้องแยกแขนงปลอดภัยต่อการอ่านทาง ไม่เอามอนทุกระดับปะปนในทางผ่านเดียวกัน

นอกCentralมีทุ่งชุมนุมกลางเชื่อมทุกภูมิภาค เป็นจุดพบกันช่วงต้น มีลานพัก ป้ายบอกทาง และจุดฝึก ไม่ใช่เมืองเผ่า

| ภูมิภาค | Field1 | Field2 | Field3 | จุดสังเกต |
|---|---|---|---|---|
| Emberheim | ถนนหินอุ่น | ป่าเถ้าถ่าน | รอยแยกบะซอลต์ | สะพานหินข้ามธารร้อน, เตาหลอมร้าง, แท่นสังเกตปล่อง |
| Ljosgard | ทางเดินใบไม้ | ป่าเรือนยอด | ป่ารากพัน | สะพานไม้เหนือคลอง, อารามเถาวัลย์ร้าง, ต้นไม้กลวงขนาดใหญ่ |
| Eirfjord | ทางน้ำอุ่น | หุบเขาน้ำค้าง | ทะเลสาบผนึก | สะพานธารน้ำละลาย, หอระฆังหิมะ, ซากวิหารน้ำพุ |
| Vanaholt | ทางประทีปรูน | ทุ่งผลึก | ซากดาวตก | เสาหินรูน, สะพานผลึกเตี้ย, วงแหวนหอดูดาวพัง |
| Aurvik | ถนนเกวียน | เหมืองผิวดิน | เหมืองชั้นลึก | เครนเหมืองเก่า, รางแร่และสะพาน, ลานหินถล่ม |
| Skuggahav | ถนนสะพานไม้ | บึงแสงหิ่งห้อย | ท่าเรือจม | ประภาคารร้าง, ระฆังแตกริมบึง, พื้นโบสถ์โผล่พ้นน้ำ |

รวมพิมพ์เขียวภายนอก **34โซน**: เมือง7 + ทุ่งกลาง1 + Field18 + เขตบอส6 + Red Zone2 ไม่รวมชั้น/ห้องในMain Quest ตัวเลขนี้คือโครงระยะยาว ไม่ใช่คำสั่งให้สร้าง34ฉากพร้อมกันสำหรับผู้เล่นทดสอบ10คน

## 4. บอสประจำแมพและเขตดูแล

บอสเป็นสิ่งมีชีวิต/ผู้เฝ้าพื้นที่ที่ผิดปกติ ไม่ใช่ผู้นำเมืองหรือผู้แทนเผ่านั้น ผู้เล่นเผ่าเจ้าบ้านไม่มีสิทธิ์พิเศษกับดรอป และไม่ได้เป็นศัตรูกับเควสเผ่าเพียงเพราะฆ่าบอสประจำภูมิภาค

ทุกบอสในตารางอยู่ในเขตPvEตามข้อเสนอแรก ผู้เล่นอื่นอาจร่วมโจมตี/แข่งสิทธิ์ตามระบบบอสที่จะกำหนด แต่ไม่ใช้กฎEXPมอนทั่วไปตัดสิน เพราะบอส **ไม่ให้EXP** มีโอกาสดรอปทองและวัสดุตามกติกาเดิม

| รหัส | บอสเสนอ | เขตดูแล / ทางเข้า | แนวการต่อสู้ |
|---|---|---|---|
| B1 | Ashfang / แอชแฟง — ราชันเขี้ยวเถ้า | ปล่องเถ้าสงัด; กิ่งแยกจาก ป่าเถ้าถ่าน | หมูป่าเกราะเถ้า พุ่งตามแนวที่เตือนและพ่นเถ้า แยกทางยืนกับจังหวะหลบ |
| B2 | Thyrnroot / เธิร์นรูท — ผู้เฝ้ารากหนาม | โพรงมหาพฤกษา; กิ่งแยกจาก ป่าเรือนยอด | ผู้พิทักษ์พฤกษาที่ผิดปกติ ใช้รากแบ่งพื้นที่และเรียกหน่อ ต้องจัดตำแหน่งและเป้าหมาย |
| B3 | Hrimveil / ฮริมเวล — ม่านน้ำค้าง | วิหารน้ำพุเยือกแข็ง; กิ่งแยกจาก หุบเขาน้ำค้าง | วิญญาณน้ำเย็นผิดปกติ เปลี่ยนแนวพื้นน้ำแข็งและจังหวะโจมตีเป็นระลอก มีสัญญาณก่อนพื้นที่อันตราย |
| B4 | Seidra / เซดรา — ผีเสื้อกระจกดารา | หอดูดาวแตกสลาย; กิ่งแยกจาก ทุ่งผลึก | ผีเสื้อเวทสร้างภาพสะท้อนและลำแสง ผู้เล่นอ่านตัวจริงและหามุมยืน ไม่ใช้สุ่มฆ่าทันที |
| B5 | Grjotmaw / กริออตมอว์ — เขี้ยวศิลา | โถงเหมืองร้าง; กิ่งแยกจาก เหมืองผิวดิน | สัตว์เกราะหินแห่งเหมือง มีช่วงเกราะปิด/เปิดและพุ่งกระแทกเสาหิน ต้องอ่านจังหวะโจมตี |
| B6 | Nokkveil / น็อกเวล — ผู้เฝ้าระฆังจม | โบสถ์ระฆังจมน้ำ; กิ่งแยกจาก บึงแสงหิ่งห้อย | ภูตหมอกและเสียงระฆัง ใช้เงาลวงกับคลื่นเป็นแนว ทางหลบมองเห็นได้ ไม่ซ่อนหลุมตายโดยไร้สัญญาณ |

แต่ละเขตบอสต้องมี: ทางเข้าที่เตือนชัด,จุดพักอยู่นอกเขตเริ่มต่อสู้,ลานหลักอ่านพื้นที่ได้,จุดสังเกตกลไก,ทางถอยกลับ และขอบเขตleash กำหนดก่อนต่อสู้ว่าบอสเดิน/ไล่ถึงไหน ไม่ลากเข้าถนนวงแหวน เมือง จุดเกิด หรือCentralได้

การหลุดleash/resetต้องกำหนดพร้อมสิทธิ์ดรอปในระบบบอส ไม่รีเซ็ตHPแบบสุ่มหรือทำดาเมจผู้เล่นนอกเขตโดยไม่เตือน ระยะเกิด ระยะไล่ เวลารอเกิด ระดับบอส จำนวนคนที่ออกแบบรับ และการแบ่งดรอปยังรอcombat/party design ไม่แต่งตัวเลขในรอบผังโลก

ไม่วางRed Zoneทับถนนจำเป็นไปCentralหรือเมืองเกิด และไม่บังคับผ่านเพื่อปลดล็อกNPCวาร์ปหลัก ทุกประตูเข้ามีคำเตือนและการเปลี่ยนภาพชัด แยกจากสีแดงประจำเผ่าMuspelborn ซึ่งไม่ได้ทำให้ทั้งภูมิภาคเป็นPvP

ผลตอบแทนที่ยืนยันคือมอนให้EXPมากขึ้น ยังไม่เพิ่มไอเท็มจำเป็นเฉพาะRed Zoneหรือกฎปล้นของจากผู้ตาย บอสถ้าจะเพิ่มในRed Zoneภายหลังยังไม่ให้EXPตามกฎบอส และต้องแยกวางกติกาใหม่ก่อน

## 6. Main Quest และห้องบอสกลางเมือง

หอผนึกรากโลกมีลานรวมตัวด้านนอก ทางเข้าห้องรอ และประตูสู่ห้องทดสอบภายใน รูปลักษณ์รากเปลี่ยนตามprogressระดับserverได้ แต่ไม่เปลี่ยนกฎเมืองCentralเป็นPvP

จำนวนชั้นยังไม่ยืนยัน100ชั้น บอสสุดท้ายยังไม่ตั้งชื่อ/เปิดเผยโครงลาสช็อตเพิ่มในรอบนี้ บอสB1–B6ไม่ใช่6บอสสุดท้ายของหอ รางวัลหอคงแรร์การันตีและความเท่าเทียมในปาร์ตี้ ส่วนสิทธิ์เผ่าของผู้ลาสบอสสุดท้ายใช้กติกาเดิมที่รอกำหนดรายละเอียด

ก่อนทำจริงต้องเลือกห้องร่วม/instance, checkpoint,การกลับเข้าหลังแพ้ และผู้มาภายหลังเข้าความคืบหน้าระดับserverอย่างไร ไม่ล็อกทุกอย่างด้วยภาพconceptเพียงแผ่นเดียว

## 7. ภาษาภาพสิ่งก่อสร้างและความชัดเจนในการเล่น

- อาคารบริการมีสัญลักษณ์อ่านได้ที่ขนาดเกม: คลัง/ถุงเงิน/เตาหลอม/รูนวาร์ป/ยา ไม่พึ่งข้อความเล็กอย่างเดียว
- ประตูที่เข้าได้ต่างจากฉากตกแต่ง บันได/สะพานที่เดินได้มีแนวแสงและขอบชัด ไม่วาดทางสวยแต่เดินไม่ได้โดยไม่มีคำอธิบาย
- ป่า/หลังคาที่บังผู้เล่นต้องออกแบบการจางหรือแยกlayer;พื้น/props/collision/navigationแยกกันก่อนประกอบ ไม่ใช้ภาพposterเป็นcollisionจริง
- ทางเข้าบอสและRed Zoneไม่ซ่อนหลังอาคารตลาด จุดวาร์ปและทางเดินไม่ให้แผงลอยบล็อก
- รูปทรงอาคารต่างกันตามวัฒนธรรมเผ่า แต่สัดส่วนประตูและทางเดินใช้มาตรฐานเดียวกันเพื่อคุมเวลาเดินและการมองบนมือถือ
- เขตเมืองและRed Zoneใช้map/zone ruleบนserver ดาเมจข้ามประตู,DoT,AoEยังต้องกำหนดในระบบPvP ไม่มีการเพิ่มสิทธิ์ตอบโต้ให้ผู้มาเยือนโดยอ้อม

## 8. ขอบเขตทำฉากจริงชุดแรกที่เสนอ

เริ่มตรวจวงจรด้วย Central + ทุ่งกลาง + Ljosgard + Field1/2ของป่า + ArenaB2 รวม6โซน เพื่อทดลองบริการ เดินทาง พื้นที่เมืองเผ่า เก็บวัตถุดิบ รวมปาร์ตี้ และบอส จากนั้นค่อยเพิ่มField3และภูมิภาคอื่นตามข้อมูล ไม่ลดจำนวนเผ่าหรืออิสระอาวุธของเกมจากการเลือกภูมิภาคทดสอบนี้

ภาพใหม่ทั้งหมดเป็นconceptและข้อมูลผัง ไม่ได้ย้ายmapปัจจุบันของเกม ไม่เปลี่ยนspawn/อุปกรณ์/สิทธิ์ผู้เล่นหรือเผยแพร่สภาพแวดล้อม
