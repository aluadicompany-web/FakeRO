# Central — expanded capital

เมืองขยายจาก28×28เป็น64×64ช่อง (พื้นที่กรอบแมพประมาณ5.2เท่า) เพื่อแยกย่านบ้านเรือน ตลาด ถนนและลานพิธีการออกจากกันจริง เมืองอื่นยังใช้ขนาดเดิม

## ย่านและความจุ

- อาคารบริการหลัก12แห่ง: ย้ายตำแหน่งให้สอดคล้องกับถนนเมืองใหม่ รักษาIDเดิมของโรงเตี๊ยม วาร์ป หอผนึกและอาคารอื่น
- บ้าน/อาคารประกอบฉาก51หลัง ใช้สไปรต์อาคาร8แบบ กระจายในย่านพักอาศัยด้านตะวันออก ใต้ และตะวันตก จัดชิดเป็นแนวชุมชนและมีทางเดินไปหน้าบ้านทุกหลัง อาคารเหล่านี้ไม่เปิดบริการหรือภายในบ้าน
- ตลาดSilfr: แผง24จุด จัดเป็นถนนยาว ร้าน12ร้านต่อฝั่ง มี3รูปแบบผ้าใบแบบสุ่มคงที่และของหน้าร้าน48ชุด เช่น ผักผลไม้ ปลา ผ้า เครื่องมือ สมุนไพรและขนมปัง ทางเข้าร้านหันเข้าหาถนนกลาง แต่ละจุดมีIDถาวร`central-stall-01`ถึง`central-stall-24`และmarketSlotหมายเลข1–24
- ลานหกเผ่า: พื้นที่เปิดกว้างบริเวณ(32,34) มีน้ำพุตรงกลาง ใช้เป็นจุดนัดพบและพื้นที่รวมตัวหน้าMain Quest
- ถนนหลัก: แนวเหนือ–ใต้ ลานกลาง ถนนขวางด้านใต้ และถนนรอบกำแพง มีป้ายบอกทางตลาด ย่านช่าง วาร์ป หอผนึกและที่พัก
- สวนและแนวแบ่งย่าน: ต้นไม้ริมถนน39ต้นและพุ่มไม้41ช่วง มีทั้งแนวต่อเนื่องและช่องข้าม พื้นที่สวนริมบึง ม้านั่ง โคมไฟและธงตามจุดสำคัญ

การจัดแผง24จุดเป็นการเตรียมพื้นที่และข้อมูลตำแหน่งสำหรับระบบร้านพ่อค้า การเช่าแผง จัดสรรผู้เช่าและซื้อขายยังไม่ได้เปิดใช้งาน ไม่ได้เพิ่มจำนวนผู้เล่นออนไลน์จากขีดจำกัดทดสอบ10คน

## โครงสร้าง

`shared/central.ts` กำหนดขนาด ย่าน อาคาร แผง สวนและสิ่งกีดขวาง `client/central-renderer.ts` วาดพื้นถนนและลาน ส่วน`client/map-renderer.ts`แสดงบ้าน/ต้นไม้/กำแพงตามขนาดแมพ ภาพใหม่`public/art/world/districts.png`มี8อาคาร พุ่มไม้ ต้นไม้และแผง2รูปแบบ ใช้ร่วมกับภาพเดิม

blocked/findPath/nearestWalkable ใช้map.sizeของแต่ละแมพแทนขอบเขต28ตายตัว การวาร์ปเข้าเมืองและทางกลับจากRoot Trialย้ายมายังตำแหน่งใหม่ การฟื้นHPอ้างอิงmap.spawn ตำแหน่งผู้เล่นเก่าที่ชนอาคารใหม่ใช้การย้ายไปพื้นที่เดินได้ใกล้สุดตามระบบโหลดเดิม ไม่รีเซ็ตตัวละครหรือรอบWorld Boss

เพิ่มปุ่ม+/−เพื่อปรับมุมมองเมืองกว้าง รักษาการเดินและต่อสู้จากsimulationเดิม แผนที่โลกปรับสัดส่วนthumbnailของCentralให้พอดี

## ตรวจสอบ

- Production build และunit/integration38รายการ รวมเดินจริงไปทุกอาคารบริการและ24แผง ตรวจทางเข้าบ้านทุกหลัง ทดสอบขอบเขตใหม่ การบันทึกพิกัดที่เกินขอบเดิม และการฟื้นHPที่จุดเกิดใหม่
- `npm run test:central`: DBแยก21ตำแหน่ง ครบ12อาคาร จุดเกิด สวน ประตู ตลาด3มุม และย่านบ้าน3มุม ตรวจatlas ภาพรวมที่ย่อกล้อง และจอ390×844
- `MAP_IDS=central_city,central_commons,eir_city npm run test:maps`: ตรวจแมพใหญ่/แมพเดิม ทางเข้าหอผนึกและNPCวาร์ปข้ามเมือง

ภาพจริงจากbrowserอยู่`artifacts/world/central-tour/` โดย`full-city.png`เป็นภาพรวมทั้งเมือง และ`market-center.png`/`residential-east.png`เป็นภาพระดับถนน

## กำแพงและรายละเอียดเมือง

กำแพงCentralสูงขึ้นเป็น86pxในฉาก มีเชิงเทินและป้อม6จุดตามมุมกับทางเข้า จางลงเมื่อบังตัวละครใกล้ขอบ ทางผ่านประตูยังเปิดและใช้การตรวจเส้นทางเดิม บ้านประกอบฉากแสดงกว้าง260pxให้แนวบ้านต่อกันทางสายตา และมีช่วงบ้านที่ติดกันจริงในข้อมูล footprint

`public/art/world/citylife.png`เพิ่มป้อม2แบบและรายละเอียดสินค้าหน้าร้าน10แบบ การสุ่มภาพบ้าน/ผ้าใบ/สินค้าทำด้วยhashประจำตำแหน่งและตัวสุ่มที่ผสมบิตเพื่อกระจายค่าระหว่างIDที่คล้ายกัน ไม่เปลี่ยนภาพเมื่อรีโหลด ไม่เกี่ยวกับสเตตัสหรือรางวัลไอเทม

ร้านมีapproachทางด้านข้างเข้าหาถนนกลาง ใช้propEntranceเดียวกันในserver/clientและการวาดเส้นทาง ของหน้าร้านเป็นภาพซ้อนภายในfootprintแผง ไม่เพิ่มสิ่งกีดขวางที่มองไม่เห็นบนถนน ตรวจคลิกร้าน10แล้วเดินเข้าหน้าต่างข้อมูลได้จริง ภาพ`market-service.png`

อ้างอิงภาพPronteraเฉพาะการแบ่งย่าน สัดส่วนอาคารและลานเปิด ผังถนน ภาพบ้าน ป้อมและองค์ประกอบเป็นของเกมนี้ ไม่คัดลอกผังหรือกราฟิกจากภาพอ้างอิง
