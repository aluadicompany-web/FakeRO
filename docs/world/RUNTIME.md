# โลกที่เล่นได้ · World runtime 0.2

งานนี้นำผังไปทำเป็นแมพจริงใน Phaser/Node ไม่ใช่เพียงรูปภาพโลก แผนภาพ/JSONในโฟลเดอร์เดิมยังเก็บแนวคิดระยะยาว ส่วนข้อมูลที่ client/server ใช้ร่วมกันอยู่ `shared/maps.ts`

## พื้นที่ที่มีจริง

35พื้นที่: Central, ทุ่งชุมนุมกลาง, เมืองเผ่า6, Field1/2/3ของแต่ละภูมิภาค18, Arenaบอสแมพ6, Red Zone2 และห้องMain Questทดลองแรก1ห้อง

- ล็อกอินด้วยบัญชี แล้วสร้างตัวละครหนึ่งตัวต่อบัญชี ทุกเผ่าเริ่มที่CentralและผูกเมืองเกิดCentral ตัวละครเก่าคงตำแหน่งเดิม ดู [ระบบบัญชี](../ACCOUNTS.md)
- แมพแต่ละห้องมีพื้น/ถนน/ขอบเขต,วัตถุวางตำแหน่งแยกตามseedแมพ,propsธีมภูมิภาค,ประตูเข้าออก และcollision
- เมืองมีอาคารที่ชนได้และหน้าต่างสถานที่,จุดบันทึกเมืองเกิด/ฟื้นHP, NPCวาร์ปไปพื้นที่ที่เคยค้นพบ
- Centralขยายเป็น64×64ช่อง มีบ้านประกอบฉาก51หลัง ถนนตลาดยาวที่มี24แผงสองฝั่ง กำแพงเชิงเทินกับป้อม6จุด ต้นไม้และแนวพุ่มแบ่งย่าน ส่วนแมพอื่นยัง28×28 รายละเอียดใน[CENTRAL.md](CENTRAL.md)
- Centralมีหอรากอิกดราซิลกลางเมือง ตลาด ลานช่าง คลัง ร้านเสบียง ลานรวมตัวและย่านบริการตามผัง หอเข้าได้จริงไปห้องRoot Warden
- แผนที่โลกกด M หรือปุ่มบนHUD แสดง35ช่องแบบmap atlas มีภาพย่อจากข้อมูลแมพ เส้นเชื่อม ประเภทพื้นที่ ตำแหน่งปัจจุบัน และปุ่มเดินไปประตูข้างเคียง ไม่ใช่กดห้องใดก็teleportได้
- การเดินใช้BFSฝั่งserver ความเร็วจำกัดและตรวจobstacle ฝั่งclientใช้ข้อมูลเดียวกันวาดถนน/ตำแหน่ง อาคาร/ต้นไม้จางเมื่อบังตัวละคร
- ผู้เล่น/มอนสเตอร์/eventsในsnapshotถูกกรองตามแมพ คนละแมพโจมตีกันไม่ได้ ไม่ส่งกระเป๋า/เงิน/พื้นที่ค้นพบของผู้เล่นอื่น

## การต่อสู้และรางวัลที่มีจริงในขอบเขตนี้

- แมพผจญภัยมีมอนสเตอร์118สายพันธุ์ ครบเลเวล3–120 แบ่งธีม6ภูมิภาค Field1ระดับต้น Field2ระดับกลาง Field3ระดับสูง ไม่เกิดในเมือง ดู [ตารางจริง](../monsters/CATALOG.md) และ [แอนิเมชั่น](../ANIMATIONS.md)
- บอส6ภูมิภาคมีภาพคนละชนิด,HP bar,การโจมตีตอบโต้และวงเตือนAoEที่มีเวลาหลบต่างกัน ยังไม่ได้ทำกลไกเฉพาะตัวทุกท่าจากdesign doc
- บอสไม่ให้EXP มอนธรรมดาให้EXPกับผู้ทำดาเมจสะสมรายบุคคลสูงสุด ระบบปาร์ตี้จริงยังไม่สร้าง จึงยังไม่มีการหารEXPในruntime
- Red Zoneเปิดการโจมตีผู้เล่นและมอนให้EXP×2 เป็นค่าทดสอบ ไม่ใช่ตัวเลขบาลานซ์สุดท้าย ปัจจุบันยังไม่มีปาร์ตี้/friendly fire policyแยก
- Central/แมพทั่วไปห้ามPvP เมืองเผ่าเจ้าถิ่นโจมตีผู้มาเยือนได้ฝ่ายเดียว ผู้มาเยือนไม่มีสิทธิ์ตอบโต้ ไม่ได้เพิ่มNPCยามที่โจมตีอัตโนมัติ
- บอสแมพให้วัสดุแก่นบอสแก่ผู้ทำดาเมจที่ยังอยู่ในห้อง เป็นreward loopต้นแบบ ไม่ใช่ตารางดรอปทอง/แดงสำเร็จรูปและยังไม่ใช่กติกาสิทธิ์ปาร์ตี้สุดท้าย
- Root Wardenเป็นบททดสอบแรก ไม่ใช่ลาสบอสสุดท้าย ไม่มีการมอบสิทธิ์พิเศษเผ่า ตัวห้องให้ตราผนึกrareต้นแบบแน่นอนแก่ผู้ทำดาเมจที่อยู่ในห้อง และบันทึกfirst-clearระดับเซิร์ฟเวอร์
- วัสดุมีIDชิ้น เก็บในกระเป๋าต้นแบบ25ช่อง เงินSilfrจากมอน,หน้าต่างสัมภาระ ถ้ากระเป๋าเต็มรางวัลบอสไปรอส่งและรับเมื่อมีช่อง ไม่ทำรางวัลหายเงียบ ๆ
- มอนเกิดใหม่12วินาที บอสประจำแมพ60วินาที เป็นค่าทดสอบ สถานะHP/เวลาเกิดถูกcheckpointพร้อมตัวละคร
- ตายกลับเมืองที่บันทึกและฟื้นHP ไม่รีเซ็ตlevel/stat/cooldown การหักEXPและชุบชีวิตยังรอระบบที่ตกลงตัวเลขภายหลัง ไม่มีการเพิ่มโทษPvP/ของตกเอง

## การบันทึกและความเข้ากันได้

Heroเพิ่มmapId,visited,bindMap,coins,loot,deliveries โดยรักษาID/สเตตัส/EXPเดิม Saveที่ไม่มีmapIdย้ายเริ่มเมืองเผ่า ผู้เล่นที่อยู่ตำแหน่งชนอาคารจากsaveเก่าปรับไปพื้นที่เดินได้ใกล้สุด

SQLiteเพิ่มworld_stateแบบadditive เก็บboss stateและrootTrialCleared การcheckpointตัวละครและworldใช้transactionเดียวกัน ปิดserverปกติ/disconnect/คำสั่งบริการ/ทุกวินาทีบันทึกข้อมูล การปิดเครื่องกะทันหันยังอาจเสียการเปลี่ยนแปลงหลังcheckpointล่าสุด ระบบหลายprocess/serverยังไม่รองรับ

## สิ่งที่ยังเป็นอาคารประกอบฉาก/ระบบที่ยังไม่ครบ

ตลาด ร้านNPC คลัง โรงช่าง ครัว และหอสภามีตัวอาคาร/ตำแหน่ง/คำอธิบายสถานที่แล้ว แต่ยังไม่มีร้านซื้อขายเต็มรูปแบบ คลังฝากของ ว่าจ้าง คราฟ ตีบวก ทำอาหาร หรือเควสเผ่าที่ใช้งานได้ อาคารเหล่านี้ไม่เปิดปุ่มบริการหลอก

ยังไม่มีอาวุธ/เกราะสวมใส่จริง,แหล่งเก็บทรัพยากร,การค้า/โยนของ30นาที,ยูนีค,ระบบบัญชี1–4ตัวเต็มรูปแบบ,admin console,เลื่อนคลาส,สกิลอาวุธครบ,ปาร์ตี้/ดรอปที่หารเท่ากัน,Main Questหลายชั้น/เนื้อเรื่องเต็ม และบาลานซ์ถึงLv.100 Level capต้นแบบยัง50 ไม่เรียกสิ่งเหล่านี้ว่าพร้อมเพียงเพราะmapมีอาคารแล้ว

## รันและตรวจ

```sh
npm ci --cache /tmp/fakero-npm-cache
npm run build
npm start
npm test
# เปิดserverทดสอบโดยใช้DBแยกก่อนคำสั่งต่อไป
CHROMIUM_PATH=/usr/bin/chromium npm run test:world
# สร้างDB fixtureและserverเฉพาะเอง ไม่แตะข้อมูลผู้เล่น
CHROMIUM_PATH=/usr/bin/chromium npm run test:maps
```
