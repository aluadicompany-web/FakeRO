# World Boss — runtime specification

## แบ่งระดับตำนาน

World Boss คืออสูร/ยักษ์จากตำนานนอร์สและซากา ดัดแปลงสำหรับเกม อยู่เหนือบอสประจำแมพ ไม่ใช้รายชื่อเดียวกับเทพและภัยหลักของ Main Quest การจัดระดับนี้เป็นการออกแบบเกม ไม่ใช่อันดับพลังตามตำนานดั้งเดิม

| World Boss | Lv. | HP | การต่อสู้จริงในต้นแบบ |
|---|---:|---:|---|
| Fafnir · ฟาฟเนียร์ | 45 | 18,000 | ลมหายใจพิษแผ่สามทิศ |
| Garmr · การ์ม | 42 | 15,000 | เขี้ยวโจมตีเป็นรูปกากบาท |
| Hraesvelgr · เฮรสเวลก์ | 44 | 16,000 | พายุหกจุดล้อมเป้าหมาย |
| Hrungnir · ฮรุงเนียร์ | 46 | 20,000 | ศิลาถล่มสามจุด |
| Draugr King · ราชันดรอว์เกอร์ | 43 | 17,000 | วงดูดชีวิต ฟื้น HP 40% ของดาเมจที่ทำได้ |
| Lyngbakr · ลิงบักร์ | 47 | 22,000 | คลื่นห้าจุดเรียงเฉียง |

ราชันดรอว์เกอร์เป็นตัวละครสร้างใหม่จากคติดรอว์เกอร์ ไม่ใช่ชื่อเทพ ส่วนลิงบักร์ใช้รูปวาฬเกาะลอยเหนือพื้นเพื่อให้เกิดในแมพบกได้ ทุกตัวมีภาพจริงแยกกัน โจมตีตอบโต้แรงกว่าบอสแมพและมีวงเตือนก่อนโจมตี เมื่อ HP ต่ำกว่า30% รัศมีสกิลเพิ่ม20% ตัวเลขเป็นค่าทดสอบ ยังไม่อ้างว่าผ่านบาลานซ์ด้วยปาร์ตี้ผู้เล่น10คน

## เทพและภัยที่สงวนสำหรับ Main Quest

- Odin, Thor, Loki, Tyr, Heimdall, Freyr: เนื้อเรื่อง การทดสอบ หรือการเผชิญหน้าขึ้นกับบท ไม่ได้หมายความว่าทุกองค์ต้องเป็นศัตรู
- Fenrir, Jormungandr, Surtr, Nidhoggr: ภัยระดับมหากาพย์สำหรับบทหลัก

รายชื่ออยู่ `shared/norse.ts` แยกจากตารางสุ่ม World Boss โดยชัดเจน ยังไม่ได้สร้างบทหลักและการต่อสู้ของรายชื่อสงวนเหล่านี้ ห้อง `root_trial` ปัจจุบันยังเป็นบททดสอบแรกเท่านั้น

## เวลาและสถานที่เกิด

- มี World Boss มีชีวิตได้ **1 ตัวทั่วเซิร์ฟเวอร์** สุ่มหนึ่งชนิดจาก6ชนิด ไม่ได้เกิด6ตัวพร้อมกัน
- รอบแรก6ชั่วโมงหลังระบบเริ่มใช้งานครั้งแรก จากนั้นใช้รอบคงที่ทุก6ชั่วโมงตามเวลาฝั่งเซิร์ฟเวอร์ การฆ่าไม่เริ่มนับใหม่
- ถ้าถึงรอบแล้วยังมีตัวเดิมอยู่ ข้ามรอบนั้น รอรอบถัดไป ไม่มีการสะสมรอบหรือเพิ่มโอกาส
- สุ่มแมพจาก27แมพนอกเมือง รวม Red Zone และห้องบอสประจำแมพ ยกเว้นห้อง Main Quest เพื่อไม่แทรกการต่อสู้ตามบท
- สุ่มตำแหน่งที่เดินถึงได้ ไม่ชนสิ่งก่อสร้าง ไม่ทับจุดเกิดผู้เล่น ประตู หรือจุดยืนบอสประจำแมพ
- บันทึก ID ชนิด ตำแหน่ง HP ยอดดาเมจของผู้ร่วมต่อสู้ และเวลารอบถัดไปใน SQLite รีสตาร์ตแล้วใช้ตัวเดิม หากปิดนานจะประเมินรอบที่ขาดครั้งเดียว ไม่ปล่อยบอสย้อนหลังหลายตัว
- บันทึกการเกิด/ข้ามรอบ/ตายก่อนส่ง snapshot; HP ระหว่างต่อสู้อยู่ใน checkpoint ทุกวินาที การปิดเครื่องกะทันหันอาจย้อน HP หลัง checkpoint ล่าสุด
- เมื่อไม่มีผู้เล่นออนไลน์ เวลาเซิร์ฟเวอร์ยังเดิน หาก process ถูกหยุดจะประเมินเมื่อเปิดใหม่ เซิร์ฟเวอร์ฟรีที่พักเครื่องจึงไม่สามารถส่งเหตุการณ์ขณะ process หยุดได้

HUD แสดงเวลาจากเซิร์ฟเวอร์หรือชื่อ/แมพ/HPของบอส คลิกเพื่อเปิดแผนที่โลกที่ทำเครื่องหมาย☠ ไม่ปลดล็อกการวาร์ปไปแมพที่ยังไม่เคยค้นพบ ไม่มีคำสั่งลัดเรียกบอสใน public API

## รางวัลและข้อจำกัด

บอสไม่ให้ EXP ต้นแบบแจกวัสดุแก่นบอสแก่ผู้ที่ทำดาเมจและยังอยู่ในแมพเมื่อบอสตาย ถ้ากระเป๋าเต็มจะรอส่ง การบันทึกวัสดุและสถานะบอสอยู่ transaction เดียวกัน ปัจจุบันยังไม่ได้ทำตารางสุ่มอาวุธทอง/แดง หรือระบบปาร์ตี้ ไม่เรียกวัสดุทดสอบนี้ว่าระบบดรอปฉบับสมบูรณ์

## ภาพแผนที่

ทุก35แมพใช้ตัวแสดงผลเดียวกัน: พื้นภูมิภาค, บ้าน/โรงช่าง/อาคารบริการ, ทางเดินตามเส้นทางที่ผ่านได้จริง, กำแพงอิฐ, พื้นน้ำ/หนอง/ลาวา, ต้นไม้/หิน และแท่นวาร์ป6ธีม สิ่งก่อสร้างที่ยังไม่มีระบบบริการคงเป็นอาคารประกอบฉากตาม `RUNTIME.md` ไม่ได้เปิดซื้อขาย/คราฟเพียงเพราะเพิ่มเท็กซ์เจอร์

ไฟล์เพิ่ม: `public/art/world/worldbosses.png`, `materials.png`, `portals.png` ภาพต้นฉบับสร้างใหม่ ไม่ใช้กราฟิกจากRO ภาพบอสยังเป็นสไปรต์เดี่ยวพร้อมการเคลื่อนไหวลอยเล็กน้อย ไม่ใช่ชุดแอนิเมชัน8ทิศ

## ตรวจสอบ

`npm test`, `npm run build`, `npm run test:maps`, `npm run test:worldboss` สองคำสั่ง browser สร้างDBและเซิร์ฟเวอร์ชั่วคราวเอง ภาพจริงเก็บใน `artifacts/world/all-maps/` และ `artifacts/world/worldbosses/` การทดสอบเวลาใช้ clock ฝั่ง simulation ที่ inject ได้ ไม่แก้เวลาหกชั่วโมงของเซิร์ฟเวอร์จริง
