# Natural landscape pass

พื้นที่ทั้ง35แมพใช้รายละเอียดตามภูมิภาค แยกป่าทึบออกจากทุ่งเปิดด้วย `shared/landscape.ts` และใช้ seed คงที่เพื่อให้เปิดใหม่แล้วต้นไม้ไม่สลับตำแหน่ง

- ป่าเรือนยอด ป่ารากพัน ป่าเถ้าถ่าน และบึงแสงหิ่งห้อย: ต้นไม้จริง100ต้นต่อแมพ ขึ้นเป็นกลุ่ม ไม่โรยห่างเท่ากันทั้งแมพ
- ทุ่งชุมนุมกลาง: ต้นไม้28ต้น เว้นลานโปร่ง มีดอกไม้ เฟิร์น หญ้าและหินมอส
- ภูมิภาคหิมะ: สนหิมะและพุ่มน้ำค้าง; เถ้าถ่าน: ไม้แห้งกับหญ้าสีทองแดง; หนองน้ำ: ไม้รากค้ำและกก; รูน: ไม้ม่วงกับผลึก; เหมือง: ต้นไม้น้อยและหญ้า/ผลึก
- เพิ่มรูปทรงพุ่มไม้ หิน และต้นไม้รวม12ชิ้นใน `public/art/world/nature.png` สลับขนาด/กลับด้านอย่างคงที่
- แสงบนพื้น สีดิน มอสและเงาใต้ต้นไม้ช่วยลดความซ้ำของพื้น ทางดินมีขอบจางและกรวดละเอียด แอ่งน้ำมีขอบโค้งและตลิ่งตามภูมิภาค เมืองมีแปลงไม้เตี้ยตามขอบ
- ต้นไม้มีการชนที่ลำต้นร่วมกันระหว่าง server/client พุ่มหญ้าและดอกไม้เป็นของตกแต่งที่เดินผ่านได้ ไม่มีการชนที่มองไม่เห็น
- กันทางเดินไปประตู ตำแหน่งมาถึง จุดเกิดผู้เล่น มอนสเตอร์และบอสก่อนปลูกต้นไม้ ลานบอสยังเปิดให้หลบสกิล
- ลดความทึบของต้นไม้/อาคารที่บังตัวละครหรือมอนสเตอร์ใกล้ตัว เพื่อรักษาการมองเห็นในการต่อสู้

ตรวจด้วย production build, unit/integration34รายการ รวมเส้นทางไปหามอนสเตอร์ทุกตัวหลังปลูกป่า และ browserเปิดทุก35แมพ ตรวจtextureทั้ง12ช่อง รวมเดินข้ามแมพ สู้มอน รีโหลดและมือถือ ภาพอยู่ `artifacts/world/all-maps/` และ `artifacts/world/01-ljosgard.png` ถึง `06-mobile-city.png`
