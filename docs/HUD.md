# HUD แบบ MMORPG

หน้าจอเล่นใช้กรอบโลหะสีน้ำเงินเข้ม ขอบทองเหลือง สัญลักษณ์รูนและไอคอนSVGวาดใหม่เข้ากับฉากแฟนตาซีนอร์ส ไม่ใช้ภาพUIจากเกมอื่น และไม่ต้องดาวน์โหลดฟอนต์หรือไอคอนจากบริการภายนอก

- ซ้ายบน: ภาพตัวละครตรงกับรูปลักษณ์ที่เลือก ชื่อ เผ่า เลเวล HP/EXP และปุ่มสเตตัส แตะภาพหรือ C เพื่อเปิดสเตตัสและใช้แต้มได้จริง
- ขวาบน: แผนที่ย่อจากข้อมูลแมพจริง พร้อมอาคาร เส้นทางที่เดินได้ ประตู ตำแหน่งผู้เล่นและมอนสเตอร์ สถานะPvPและพิกัด กดแผนที่ย่อหรือ M เพื่อดูโลก35แมพ มีรอบWorld Bossและบันทึกสำรวจที่ยุบได้
- กลางบน: ชื่อ เลเวลและHPของเป้าหมายที่เลือก ปิดด้วยปุ่ม × เพื่อหยุดโจมตี
- ด้านล่าง: 1 โจมตีเป้าหมายปัจจุบันหรือมอนสเตอร์ใกล้ที่สุด, 2 โหมดกายภาพ, 3 โหมดเวท, 4 หยุด แสดงคูลดาวน์จากเวลาฝั่งเซิร์ฟเวอร์ อาวุธฝึกอยู่ในเมนูย่อย และมีEXPที่ขอบแถบ
- ขวาล่าง: กระเป๋า B, สารานุกรม N, เมนูช่วยเหลือ ปรับซูมและออกจากเกม
- ซ้ายล่าง: บันทึกเหตุการณ์ต่อสู้ล่าสุด ยุบได้ จอแนวนอนที่เตี้ยจะซ่อนบันทึกเพื่อไม่ทับแถบคำสั่ง

ช่องสกิลอาชีพสองช่องแสดงแม่กุญแจและปิดการกดไว้ **ไม่มีการสร้างสกิลหรือแถบSPจำลองที่ยังไม่มีกลไกจริง** อาวุธฝึกยังเป็นตัวเลือกทดสอบ ระบบไอเทมและการปลดล็อกสกิลจริงแยกพัฒนาภายหลัง

UIใช้DOMแยกจากPhaser ป้องกันคีย์ลัดต่อสู้เมื่อกำลังกรอกข้อมูลหรือเปิดหน้าต่าง และกั้นการคลิกฉากระหว่างแสดงรหัสกู้คืน เมนูย่อยเปิดครั้งละหนึ่งหน้าต่างเพื่อลดการซ้อนบนมือถือ Esc ปิดหน้าต่างปัจจุบัน ข้อความแจ้งเตือนทั่วไปจางออกหลัง4.5วินาที เคารพการตั้งค่า reduced-motion

## ตรวจสอบ

`npm run build` และ `npm run test:hud` ตรวจตำแหน่งHUD/ขอบจอ/การซ้อนกันที่1440×900,1366×768,1024×768,768×1024,390×844,360×800,844×390 รวมการใช้แต้มสเตตัส เมนูกระเป๋า แผนที่35แมพ สารานุกรม เปลี่ยนอาวุธ สลับโหมด โจมตีจริง แถบเป้าหมาย คูลดาวน์ และหยุดโจมตี ไม่มีpage errorในรอบทดสอบ ใช้ฐานข้อมูลและเซิร์ฟเวอร์ชั่วคราวแยกจากผู้เล่นจริง

หลักฐานภาพอยู่ `artifacts/hud/` รวมภาพเมือง การต่อสู้ สเตตัส มือถือ และจอแนวนอน โค้ดกรอบ/ไอคอน/แผนที่ย่ออยู่ `client/hud.ts` ธีมและขนาดหน้าจออยู่ `client/hud.css` การผูกคำสั่งเดิมอยู่ `client/main.ts` ไม่มีการเปลี่ยนสูตรดาเมจหรือข้อมูลผู้เล่นในงานUIนี้
