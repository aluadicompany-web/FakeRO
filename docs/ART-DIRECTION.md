# Art direction · Revision 3 — painted SD characters

เป้าหมายคือ **Classic Japanese SD / chibi JRPG anime** ตามภาพอ้างอิงและชุดที่ตกลงกับผู้ใช้: ประมาณ3หัว ดวงตาอนิเมะทรงยาว ใบหน้ามน ช่อผมมีมิติ เส้นขอบบางสีน้ำตาลเข้ม ผ้าพับ หนัง เข็มขัดและรองเท้ามีแสงเงา ไม่ใช้รูปทรงเหลี่ยมของSVGต้นแบบ64×96เป็นภาพตัวละครจริงอีก

## ภาพที่โหลดใช้จริง

หน้าสร้างตัวละคร ภาพโปรไฟล์บนHUD และPhaserใช้ชุดภาพเดียวกันจาก `public/art/characters/` และใช้ดัชนีร่วม `shared/character-art.ts` ค่าart versionคือ `painted-sd-v3` ตัวละครในฉากใช้ภาพความละเอียด128×192ต่อเฟรมแล้วแสดง64×96 ส่วนหน้าสร้างใช้ต้นฉบับ256×384ต่อเฟรมเพื่อเห็นรายละเอียด

- **ชุด24เฟรม**:6เผ่า ×2เพศ ×หน้า/หลัง รักษาชุดคอนเซปต์ `art/style-v2-characters.png`:แดงนักดาบ เขียวนักธนู ฟ้า–ขาวนักบวชสนับสนุน ม่วงนักเวท ทองพ่อค้า และดำโจร ไม่มีอาวุธผูกติดกับชุด
- **ศีรษะ20เฟรม**:5ทรงผมต่อเพศ ×2เพศ ×หน้า/หลัง ใบหน้าลงสีจริง แยกชั้นผมกับม่านตาเป็นraster masks จึงเปลี่ยนผม6สีและตา5สีได้ทุกเผ่าโดยไม่ย้อมสีผิวหรือชุด
- **ชุดขยับได้5ชิ้น**:ลำตัว แขนซ้าย/ขวา ขาซ้าย/ขวา ที่แบ่งจากภาพชุดเดียวกัน ตรวจว่ารวมชิ้นกลับแล้วไม่ขาดพิกเซลทั้ง24เฟรม ศีรษะและผมยาวมีการซ้อนหน้า/หลังลำตัวตามทรงผม
- ใช้ภาพหน้า/หลัง ผสมการกลับด้านและปรับมุมเพื่อแสดง8ทิศ การเดิน โจมตี โดนตีและตายยังใช้rigขยับข้อต่อ ไม่ใช่ชุดภาพวาดอิสระ8ทิศทุกเฟรม อาวุธ/เอฟเฟคยังใช้ระบบเดิม
- ภาพPreviewใช้SVGเป็นตัวประกอบภาพrasterและฟิลเตอร์สี ไม่ได้วาดตัวละครด้วยpolygonแบบต้นแบบเดิม ในเกมโหลดsprite sheetsโดยตรงและใช้linear filtering

## ไฟล์และการสร้างซ้ำ

ต้นฉบับภาพวาดใหม่อยู่ `art/characters-v3-costumes-source.png` และ `art/characters-v3-heads-source.png` สร้างในหนึ่งpassต่อatlasจากภาพชุดที่ตกลงไว้ ดัชนีชุดเรียงmuspel,alf,jotun,vanir,nid,skug แถวชายหน้า/หญิงหน้า/ชายหลัง/หญิงหลัง ทรงผมเรียง5แบบต่อแถวในลำดับเพศ/ทิศเดียวกัน

`npm run art:characters` (สำหรับผู้เตรียมasset ต้องมีChromiumและPython/Pillow) ใช้Canvasตัดกรอบโปร่งใส จัดเท้า/คอด้วยสเกลร่วม แยกmaskสีผม/ตาและชิ้นส่วนrig แล้วเข้ารหัสWebPแบบlosslessโดยตรวจRGBAตรงกับPNGทุกพิกเซล Metadataอยู่ `public/art/characters/manifest.json` ภาพcontact sheetและหลักฐานเกมอยู่ `artifacts/characters-v3/` (ไม่รวมGit)

ภาพเก่า `style-v2-sprites.*`, `hairstyles-and-eyes.*`, `starter-costumes-concept.png` และ `style-v2-atlas-study.png`เก็บเป็นประวัติ/แนวทาง ไม่ได้ลงทะเบียนเป็นตัวละครที่โหลดในเกม

## รูปลักษณ์และข้อมูลเดิม

คงschema `appearance: {gender,hair,eyes,hairColor}` และตัวเลือกเดิมทั้งหมด รวม1800รูปลักษณ์ ไม่มีการเปลี่ยนเลเวล สเตตัส ชุดตามเผ่า บัญชี หรือฐานข้อมูลตัวละคร การอัปเดตภาพใช้กับตัวละครเดิมทันทีเมื่อเปิดclientเวอร์ชันใหม่ ไม่ต้องสร้างตัวละครซ้ำ

## ตรวจภาพและการใช้งาน

`npm run test:character-art`ตรวจภาพที่เรนเดอร์จริงครบ12ชุดชาย/หญิง ทรงผม10แบบ ผม6สี ตา5สี ภาพโปรไฟล์/ตัวละครในCentral/โจมตีจริง/โหลดใหม่ และมือถือ พร้อมตรวจไฟล์ภาพไม่หาย `npm run test:character-cast`เปิดผู้เล่นจริง6คนต่อรอบเพื่อตรวจ12ตัวละคร/24ภาพชุดหน้า–หลังในฉากเดียวกัน `npm test`ผ่าน54กรณี รวม1800combinationsและดัชนีหน้า/หลัง การทดสอบเดิม `test:animations`ยังตรวจ8ทิศและอาวุธ17แบบได้ด้วยrigใหม่

ฉากใช้โลกไอโซเมตริกอนิเมะ35แมพที่มีcollision/เส้นทางจริงแล้ว รายละเอียดอยู่ `world/RUNTIME.md` งานนี้เปลี่ยนภาพตัวละครและการแสดงผล โดยไม่เปลี่ยนสูตรต่อสู้หรือเศรษฐกิจ
