# อุปกรณ์พื้นฐาน Lv.10–100 · ขาวและฟ้า

ขอบเขตล่าสุดตามผู้ใช้: **Lv.10 / 20 / 40 / 60 / 80 / 100**, อาวุธและโล่ 8 ประเภท รุ่นละ 2 สี รวม **96 รายการ** อาวุธทองและแดงแยกออกจากชุดนี้ทั้งหมด ไม่รวมมีดเริ่มต้น Lv.1 และอาวุธคลาส 2/ยูนีค เช่น ขวาน ค้อนใหญ่ ธนูหนัก/เบา คาตานะ ดาบคู่

นี่เป็นงานออกแบบรูปลักษณ์และแค็ตตาล็อก ยังไม่เพิ่ม inventory, equip, crafting หรือ drop เข้า runtime และไม่เพิ่ม level cap ปัจจุบันของตัวละครเป็น 100 โดยอัตโนมัติ ค่า ATK/MATK/DEF รุ่นสูงยังไม่กำหนด ไม่ใช้ตัวเลขเดาแล้วอ้างว่าบาลานซ์เสร็จ

## โครงสร้างรุ่นและที่มา

| รุ่น | ช่วงเป้าหมาย | ชุดวัสดุ | จุดพัฒนาภาพ |
|---|---|---|---|
| Lv.10 | 10–19 | เหล็กพื้นฐาน ไม้ทั่วไป หนังฟอก หินเวทดิบ | ทรงเรียบ เห็นหมุด ขอบเหล็กและหนังพันด้าม ไม่มีลายซับซ้อน |
| Lv.20 | 20–39 | เหล็กกล้า ไม้แอช หนังเย็บเสริม หินเวทเจียระไนขั้นต้น | ทนทานขึ้น เสริมขอบและจุดรับแรง รูปทรงภาคสนาม |
| Lv.40 | 40–59 | เหล็กกล้าชุบแข็ง ไม้เหล็กสีเข้ม ควอตซ์ เส้นใยทนแรง | วัสดุเข้มตัดกับคมเหล็กอ่อน ร่องใบและการ์ดเริ่มมีเอกลักษณ์ |
| Lv.60 | 60–79 | โลหะผสมสีเงินเย็น ไม้เบิร์ช หนังน้ำเงินเข้ม ควอตซ์เย็น | ผิวโลหะโทนเย็นและไม้สีอ่อน แสงสะท้อนธรรมชาติ ไม่ปล่อยออร่า |
| Lv.80 | 80–99 | เหล็กรูนเทาคราม ไม้ครามเนื้อแน่น โลหะเงิน หนังเทา | รูปทรงเรขาคณิตแม่นยำ พื้นเข้มกับขอบเงิน ลวดลายอ่านง่าย |
| Lv.100 | 100+ | ไม้จากเขตรากโลก โลหะตีชั้นสีอ่อน หนังถ่าน แร่ประกายมุก | วัสดุพื้นฐานระดับสูง งานเรียบสัดส่วนงาม คมโลหะเหลือบอ่อน ไม่ใช่ของตำนาน |

- **ขาว:** ดรอปจากมอนสเตอร์ทั่วไปและบอสในพื้นที่ที่เหมาะกับระดับอุปกรณ์ วัสดุและงานประกอบดีขึ้นตามรุ่น แต่ไม่มีสกิลเฉพาะบอสหรือออร่าใหญ่
- **ฟ้า:** พ่อค้า/ช่างคราฟจากวัตถุดิบทั่วไปเกรดตรงรุ่น เห็นฝีมือช่างจากการตีชั้น จุดรับแรง การยึด และรูนขนาดเล็ก ความชำนาญส่งผลต่อคุณภาพภายในเพดานของสูตร ไม่สร้างพลังไร้ขีดจำกัด
- **สีหมายถึงพื้นหลังไอคอน:** ขาว/ฟ้า ไม่บังคับวัสดุอาวุธให้เป็นสีนั้น ทุกเผ่าใช้และเลือกเส้นทางความชำนาญได้ตามกติกาเดียวกัน
- Lv.100 ยังเป็นของพื้นฐานระดับสูง ไม่ต้องใช้แก่นบอส Main Quest หรือวัตถุดิบเฉพาะบอสเพื่อคราฟฟ้า แร่ประกายมุกเป็นแร่ธรรมชาติ ไม้เขตรากโลกเป็นวัตถุดิบพื้นที่ทั่วไป ไม่ใช่หัวใจอิกดราซิลหรือของพิชิตบอส
- คงชนิดอาวุธ/จำนวนมือทุกระดับ เปลี่ยนวัสดุและ silhouette ไม่เปลี่ยนเงื่อนไขคลาสด้วยเลเวลอุปกรณ์ มีดสั้นต้องสั้นกว่าดาบ คทาต้องสั้นกว่าไม้เท้า ค้อนยังเป็นค้อนเล็กมือเดียว
- รูนฟ้ามีเพียงแสงบาง ไม่ใช้ปีก ชิ้นส่วนลอย ผลึกยักษ์ หรือเอฟเฟกต์กลบตัวละคร เพื่อสงวนภาษาภาพของทองและแดง
- จำนวนวัตถุดิบ อัตราดรอป ราคา สเตตัส และ threshold ความชำนาญต้องกำหนดตอนทำระบบต่อสู้/เศรษฐกิจ ไม่ได้ถูกตัดสินจากภาพโปสเตอร์

## แค็ตตาล็อกภาพและชื่อ

แต่ละแผ่น: คอลัมน์จากซ้าย ดาบยาว / ดาบใหญ่ / โล่ / ไม้เท้า / คทา / มีดสั้น / ธนู / ค้อนเล็ก แถวบนขาว แถวล่างฟ้า ชื่อภาษาไทยในตาราง/JSON เป็นข้อมูลอ้างอิงหลัก ข้อความบนภาพเป็นเพียงป้ายอธิบายงานออกแบบ ไม่ใช่ item ID

### Lv.10 — ผู้เริ่มเดินทาง / Wayfarer

[เปิดแผ่นออกแบบ Lv.10](art/level-010.png)

ฟ้าแตกต่างจากขาว: ตีประสาน ขัดขอบให้เรียบ ยึดชิ้นส่วนแน่นขึ้น มีรูนเล็ก

| ประเภท | ขาว | ฟ้า | รูปทรงประจำรุ่น |
|---|---|---|---|
| ดาบยาวมือเดียว | ดาบลาดตระเวน | ดาบเหล็กตีประสาน | ใบตรง การ์ดเหล็กเรียบ |
| ดาบใหญ่สองมือ | ดาบใหญ่ผู้เดินทาง | ดาบใหญ่เหล็กถ่วงสมดุล | ใบกว้างปลายตัด ด้ามหนังยาว |
| โล่ | โล่ไม้หุ้มเหล็ก | โล่เหล็กช่างรูน | ไม้กลมขอบเหล็ก |
| ไม้เท้าสองมือ | ไม้เท้าผู้ฝึกเวท | ไม้เท้ารูนขัดเงา | ก้านไม้ตรง หินเวทดิบที่ปลาย |
| คทามือเดียว | คทาผู้เริ่มพิธี | คทารูนประสาน | ก้านไม้สั้น หินขนาดเล็ก |
| มีดสั้น | มีดสั้นเดินป่า | มีดสั้นเหล็กสมดุล | ใบสั้นตรง การ์ดเล็ก |
| ธนู | ธนูไม้ผู้เฝ้าป่า | ธนูไม้ประสาน | โค้งไม้ธรรมชาติ ด้ามหนัง |
| ค้อนเล็ก | ค้อนช่างฝึกหัด | ค้อนเหล็กถ่วงสมดุล | หัวเหล็กเหลี่ยม ด้ามไม้สั้น |

ฟ้าแตกต่างจากขาว: ประกอบแนบสนิท เดินตะเข็บหนัง มีลายปมมุมเหลี่ยมและรูนขนาดเล็ก

| ประเภท | ขาว | ฟ้า | รูปทรงประจำรุ่น |
|---|---|---|---|

| ดาบใหญ่สองมือ | ดาบใหญ่ลาดตระเวน | ดาบใหญ่สมดุลชายแดน | ปลายตัดเฉียง ด้ามยาวเสริมปลอก |
| โล่ | โล่เฝ้าด่าน | โล่ประสานชายแดน | ไม้กลมมีค้ำเหล็กรัศมี |
| ไม้เท้าสองมือ | ไม้เท้าแอช | ไม้เท้าแอชจารึกรูน | ก้านแอชปลายแยกง่ามรองหิน |
| คทามือเดียว | คทาแอช | คทาแอชฝังผลึก | ก้านสั้น ปลายวงเหล็กรองหินมน |
| มีดสั้น | มีดสั้นเหล็กกล้า | มีดสั้นคมประสาน | ใบทรงใบไม้ มีปุ่มกันนิ้ว |
| ธนู | ธนูแอชเสริมแรง | ธนูแอชไม้ซ้อน | แขนธนูแอชโค้งกลับ เสริมปลาย |
| ค้อนเล็ก | ค้อนเหล็กแปดเหลี่ยม | ค้อนสมดุลแปดเหลี่ยม | หัวแปดเหลี่ยม ด้ามสั้นพันหนัง |

[เปิดแผ่นออกแบบ Lv.40](art/level-040.png)

ฟ้าแตกต่างจากขาว: ร่องรูนเส้นบางต่อเนื่อง งานไม้แกะและการตีซ้อนชั้น อ่านเป็นฝีมือช่าง

| ประเภท | ขาว | ฟ้า | รูปทรงประจำรุ่น |

| ดาบใหญ่สองมือ | ดาบใหญ่ร่องคู่ | ดาบใหญ่ร่องคู่ตีชั้น | ร่องคู่บนใบ ดุมด้ามทรงข้าวหลามตัด |
| โล่ | โล่ไม้เหล็ก | โล่ปมไม้เหล็ก | ไม้สีเข้ม ค้ำเหล็กลายปมตัดกัน |
| ไม้เท้าสองมือ | ไม้เท้าพฤกษาวน | ไม้เท้าพฤกษารูน | ก้านแกะเกลียว ปลายควอตซ์เหลี่ยม |
| คทามือเดียว | คทาควอตซ์ | คทาควอตซ์กรอบเงิน | ควอตซ์เล็กในกรอบโปร่ง ด้ามสั้น |
| มีดสั้น | มีดสั้นหยดเหล็ก | มีดสั้นหยดเหล็กรูน | ใบสั้นปลายหยดน้ำไม่สมมาตร |
| ธนู | ธนูไม้เหล็ก | ธนูไม้เหล็กประสาน | ไม้ซ้อนสีเข้ม เสริมแผ่นโลหะรูปใบไม้ |
| ค้อนเล็ก | ค้อนหน้าเฉียง | ค้อนหน้าเฉียงจารึกรูน | หัวสี่เหลี่ยมหน้าตัดเฉียง ด้ามสั้น |

ฟ้าแตกต่างจากขาว: ข้อต่อประสาน ลายรูนน้ำค้าง และขอบขัดคม ผลึกเล็กมีแสงน้อย

| ประเภท | ขาว | ฟ้า | รูปทรงประจำรุ่น |
|---|---|---|---|
| ดาบยาวมือเดียว | ดาบเหมันต์ | ดาบเหมันต์ตีประสาน | สันใบยก การ์ดเกล็ดหิมะขนาดเล็ก |
| ดาบใหญ่สองมือ | ดาบใหญ่เหล็กเย็น | ดาบใหญ่เหล็กเย็นจารึกรูน | ใบกว้าง ไหล่ใบสองขั้น ด้ามยาว |
| โล่ | โล่เงินเหมันต์ | โล่รูนน้ำค้าง | ผิวเงิน มีร่องรัศมีหกแนว |

| คทามือเดียว | คทาผลึกน้ำแข็ง | คทาผลึกน้ำแข็งประสาน | ผลึกเล็กในวงโปร่งเหนือด้ามสั้น |
| มีดสั้น | มีดสั้นใบน้ำค้าง | มีดสั้นใบน้ำค้างขัดคม | ใบสั้นโค้งแบบใบน้ำค้าง |
| ธนู | ธนูเบิร์ชเยือกแข็ง | ธนูเบิร์ชเสริมโลหะเย็น | แขนไม้สีอ่อนเสริมโลหะที่ปลาย |
| ค้อนเล็ก | ค้อนเงินเหมันต์ | ค้อนเงินเหมันต์สมดุล | หัวหกเหลี่ยมเงินเย็น ด้ามหนังสั้น |

ฟ้าแตกต่างจากขาว: เห็นชั้นตีโลหะ ข้อต่อเข้าล็อก และแนวรูนฟ้าเส้นเล็ก ไม่ใช้หนามใหญ่

| ประเภท | ขาว | ฟ้า | รูปทรงประจำรุ่น |

| ดาบใหญ่สองมือ | ดาบใหญ่เหล็กรูน | ดาบใหญ่รูนประกบชั้น | ใบเทาครามบากใกล้โคนเล็กน้อย ด้ามยาว |
| โล่ | โล่ไม้คราม | โล่ปมรูนไม้คราม | ไม้ครามขอบเงิน ดุมลายรากเรขาคณิต |

| ธนู | ธนูไม้ครามเสริมเหล็ก | ธนูไม้ครามตีประสาน | ไม้โค้งคราม เสริมแถบเหล็กบาง |

## หลักการวางพลังสำหรับขั้นต่อไป

ของฟ้ารุ่นเดียวกันควรมีคุณภาพฐานและความยืดหยุ่นจากการคราฟดีกว่าขาว แต่ยังต้องยอมเปลี่ยนรุ่นเมื่อเลเวลเพิ่ม ของฟ้า Lv.20 ที่คุณภาพสูงไม่ควรทำให้ขาว Lv.40 หมดประโยชน์ทั้งหมด ต้องวัดทั้ง DPS, healing, การป้องกัน และต้นทุน ไม่ตัดสินจาก ATK อย่างเดียว

ขาวและฟ้าใช้สูตรคนละส่วนกับเอฟเฟกต์เฉพาะของทอง/แดง เมื่อทำระบบจริงต้องกำหนด attack interval, การคำนวณเกราะ, AGI, สกิล และคุณภาพช่างร่วมกัน ค่าสเตตัส Lv.10 จากเอกสารเก่าเป็น draft เดิม ไม่ได้เป็นสูตรอัตโนมัติคูณยกไปถึง Lv.100
