# แอนิเมชั่นและการโจมตีต้นแบบ

## สิ่งที่เปิดดูและเล่นได้

ปุ่ม **สารานุกรม** แสดงมอนสเตอร์118สายพันธุ์ครบทุกเลเวล3–120 พร้อมชื่อ แมพ HP/ATK และบอส13ตัว (บอสแมพ6, Root Warden1, World Boss6) เลือกยืน เดิน โจมตี และภาพหน้า/หลังได้ ค้นหาชื่อหรือเลเวลได้ ดูรายการทั้งหมดใน [CATALOG.md](monsters/CATALOG.md) ซึ่งส่งออกจาก `shared/monsters.ts` ด้วย `npm run export:monsters` มี JSON/CSV ในโฟลเดอร์เดียวกัน

มอนสเตอร์แบ่ง6ภูมิภาคให้เข้ากับป่า หิมะ ภูเขาไฟ ป่ารูน เหมือง และบึงเงา Field1รับระดับต้น Field2ระดับกลาง Field3ระดับสูง ตำแหน่งเกิดเลือกเฉพาะพื้นเดินได้ที่เชื่อมกับทางเข้า เว้นประตูและพื้นที่เมืองทั้งหมด เมืองทั้ง7แห่งไม่มีมอนสเตอร์ ระบบ World Boss เดิมยังใช้รอบ6ชั่วโมงและไม่เกิดซ้ำขณะที่ตัวเดิมยังอยู่

ปุ่ม **อาวุธฝึก** เปลี่ยนอาวุธได้17แบบ: มีดเริ่มต้น ดาบมือเดียว ดาบใหญ่ โล่ ไม้เท้า คฑา มีดสั้น ธนู ค้อนเล็ก ดาบกับโล่ ค้อนกับโล่ ค้อนใหญ่ ขวาน ธนูใหญ่ ธนูเล็ก คาตานะ และดาบคู่ แต่ละชนิดมีระยะ ความเร็ว ช่วงง้าง และกำลังโจมตีแยกกัน พร้อมท่าฟัน แทง ฟันกว้าง ทุบ กระแทกโล่ ยิงธนู ยิงเวท และฟันสองครั้ง เอฟเฟคแสดงเส้นคมดาบ ลูกธนู กระสุนเวท วงเวท ฝุ่นและแรงกระแทกตามชนิด

**อาวุธฝึกเป็นตัวเลือกทดสอบ ไม่ใช่ระบบคราฟ สวมใส่ ซื้อขาย หรือปลดล็อกยูนีคสกิลจริง** ทุกเผ่าทดลองได้ การถืออาวุธขั้นสูงในต้นแบบไม่ได้หมายความว่าได้ไอเทมนั้นแล้ว

## งานภาพและขอบเขต

- ตัวละครชาย/หญิงใช้รูปลักษณ์เดิมและโครงกระดูกแยกศีรษะ ลำตัว แขน ขา และอาวุธ มีท่ายืน เดิน โจมตี สะดุ้ง และล้ม ใช้ภาพหน้า หลัง ด้านข้างและการสะท้อนเพื่อหัน8ทิศ ไม่ใช่ภาพวาดแยก8ทิศทุกเฟรม
- มอนสเตอร์118สายพันธุ์สร้างจาก24รูปร่างพื้นฐาน มีสี ขนาด ลำดับขั้นและเครื่องหมายต่างกันตามสถานที่ เป็น118รายการเล่นจริง ไม่ใช่118โครงร่างภาพที่วาดแยกทั้งหมด
- บอส13ตัวมีรูปร่างและการโจมตีธรรมดา รวมระบบวงเตือนAoEที่มีอยู่ บอสระดับเทพซึ่งสงวนไว้ให้ Main Quest อนาคตยังไม่ถูกนำมาเกิด
- ภาพมอนสเตอร์และบอสรวม296คีย์เฟรม:37รูปร่าง ×2ด้าน ×4ท่า (ยืน เดินA เดินB โจมตี) ท่าโดนตี/ตายใช้การขยับ สั่น ยุบและจางจากภาพเหล่านี้ ระหว่างเฟรมมีการเคลื่อนไหวเสริม ไม่ใช่แอนิเมชั่นวาดทุกเฟรม
- ภาพแถบต้นฉบับอยู่ `public/art/monsters/*.png` ภาพที่โหลดจริงเป็น WebP แบบ lossless ที่ตรวจ RGBA ตรงกันทุกพิกเซล ลด39,530,496เป็น29,047,628ไบต์ รวม14ไฟล์ แต่ยังถือว่าหนักสำหรับมือถือสเปกต่ำ ต้องปรับต่อก่อนเปิดบริการจริง
- `prepareAnimationAtlas` ตัดพื้นโปร่งใสและใช้สเกลเดียวกันทุกท่าหน้า/หลังของรูปร่างเดียวกัน ยึดเท้าที่ตำแหน่งเดียว ลดอาการขนาดกระโดดและเท้าลอย แล้วปล่อย texture ต้นฉบับที่ไม่ใช้

## ฝั่งเซิร์ฟเวอร์

เซิร์ฟเวอร์กำหนดช่วงง้าง เวลาปะทะ ระยะ และดาเมจ ส่งเฉพาะเหตุการณ์ให้ภาพแสดงตามเวลา โจมตีไม่หักHPทันทีเมื่อกด เปลี่ยนอาวุธหรือเชื่อมต่อใหม่ไม่ล้างคูลดาวน์ ตรวจเป้าหมายมีชีวิต แมพเดียวกัน ระยะและสิทธิ์PvPซ้ำตอนปะทะ ยกเลิกการโจมตีที่ค้างเมื่อผู้โจมตีตาย เปลี่ยนแมพ หรือเป้าหมายหลุดระยะ การตีประชิดหลบออกจากระยะได้

มอนสเตอร์เดินลาดตระเวน ไล่ ตี กลับพื้นที่เดิม และฟื้นHPหลังพ้นการต่อสู้ มีระยะไล่จำกัดและรีเซ็ตเครดิตความเสียหายเมื่อฟื้นเต็ม ผู้เล่นที่ภาพยังโหลดไม่เสร็จจะไม่เป็นเป้าหมายจน client พร้อม เส้นทางเดินใช้8ทิศโดยห้ามตัดมุมวัตถุชน

เลเวลต้นแบบขยายถึง120 แต้มพื้นฐานต่อสเตตัสสูงสุด99 สูตรHP/ATK/EXPอยู่ในข้อมูลร่วม ระดับสูงและการเปลี่ยนสายยังต้องทดสอบสมดุลร่วมกับระบบอุปกรณ์ สกิลและปาร์ตี้จริง ตัวเลขนี้ไม่ใช่สมดุลฉบับเปิดบริการ

## การตรวจสอบ

- `npm test`:47กรณีผ่าน รวม118ระดับ/ชื่อ/แมพ จุดเกิดเดินถึงและไม่อยู่ในเมือง อาวุธ17แบบ เวลาปะทะ คูลดาวน์ การเปลี่ยนแมพ AI บอส13ตัว ข้อมูลส่วนตัว และSQLite
- Browser: วาดครบ35แมพ, ทดลองอาวุธ17ชนิดพร้อมเอฟเฟค, World Boss6ชนิด, สารานุกรม118ตัว+บอส13ตัว/สามท่า/หน้า-หลัง, ตัวละคร8ทิศ และขนาดหน้าจอมือถือ ไม่พบ page error ในรอบทดสอบ
- เส้นทางเล่นจริง: สร้างตัวละคร ออกจากเมือง ต่อสู้ เปลี่ยนแมพ กลับCentral โหลดใหม่แล้วจำตำแหน่ง/แมพที่ค้นพบได้ มือถือไม่มีหน้าล้น
- หลักฐานภาพ/วิดีโออยู่ `artifacts/animations/` และสคริปต์ `scripts/playtest-animations.ts` ใช้ฐานข้อมูลแยกจากผู้เล่นจริง มีโหมด `ANIMATION_PART=gallery` หรือ `weapons`

ยังไม่มีระบบปาร์ตี้ แบ่งรางวัล ซื้อขาย อุปกรณ์เต็มระบบ สกิลอาชีพ เสียง หรือMain Questครบชุด งานนี้ไม่เผยแพร่เกมภายนอก
