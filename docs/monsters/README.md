# ข้อมูลมอนสเตอร์

[ตารางเลเวล3–120](CATALOG.md) มี118สายพันธุ์ หนึ่งชนิดต่อเลเวล พร้อมแมพและค่าสำหรับต้นแบบ สร้างจากข้อมูลที่เซิร์ฟเวอร์ใช้จริงด้วย `npm run export:monsters` มี `catalog.json` และ `catalog.csv` สำหรับนำไปตรวจสมดุลต่อ

เปิด **สารานุกรม** ในตัวเกมเพื่อดูภาพเคลื่อนไหว หน้า/หลัง และบอส13ตัว ไม่ต้องพึ่งไฟล์ภาพแนบในแชต รายละเอียดรูปแบบภาพ กติกาเกิดและข้อจำกัดอยู่ใน [ANIMATIONS.md](../ANIMATIONS.md)
