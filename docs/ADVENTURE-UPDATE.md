# Central / Equipment / Population · Playable update

## การเดินและพื้นที่พัก

ความเร็วเดินจาก2.3เป็น2.6ช่อง/วินาที (+13%) ใช้ความเร็วและเส้นทางฝั่งเซิร์ฟเวอร์เหมือนเดิม Centralมีเขตพักรัศมี7.5ช่องรอบน้ำพุที่(32,34) แสดงขอบเขตและป้ายHP/MP ฟื้นHP6%และMP10%ของค่าสูงสุดต่อวินาทีเฉพาะผู้มีชีวิตในเขตนั้น ไม่เกินค่าสูงสุด

MPเป็นค่าจริงที่บันทึกลงฐานข้อมูล:ค่าสูงสุด40+5×เลเวล+5×INT เวทพื้นฐานใช้3+floor(เลเวล/30)MPต่อครั้ง ทั้งโหมดเวทและอาวุธไม้เท้า/คทา เมื่อMPไม่พอจะไม่สร้างดาเมจหรือเอฟเฟคโจมตี กายภาพไม่ใช้MP ตัวละครเก่าที่ไม่มีMPได้รับค่าสูงสุดของตัวเองเมื่อโหลด ไม่รีเซ็ตบัญชี/รูปลักษณ์/ความคืบหน้า

## GM

ปุ่ม **เครื่องมือGM** และ **แต่งตัวละคร** อยู่ใต้ข้อมูลโปรไฟล์โดยตรง แต่งตัวกลับไปใช้หน้าสร้างเดิมเพื่อเปลี่ยนชื่อ เผ่า เพศ ผม/ตาของตัวละครเดิม คงID เลเวล EXP เงิน ไอเทมและพื้นที่ค้นพบ ปิดการเชื่อมต่อฉากก่อนแก้แล้วกลับเข้าเล่นได้ ไม่สร้างตัวละครที่สอง หากเปลี่ยนเผ่าจนสเตตัสไม่ถึงเงื่อนไขอาวุธ อาวุธยังอยู่ในกระเป๋าและถูกถอดตามกติกาปกติ

ทุกคำสั่งGMตรวจaccount session/roleฝั่งเซิร์ฟเวอร์ มีaudit การแก้รูปลักษณ์ปฏิเสธขณะยังเชื่อมต่อฉากอยู่ ผู้เล่นทั่วไปใช้คำสั่งนี้ไม่ได้ ตัวเลือกอาวุธฝึก17แบบเปิดเฉพาะGM ผู้เล่นทั่วไปสวมจากไอเทมที่ตนมีและมีคุณสมบัติถึงเกณฑ์

## อาวุธที่นำเข้าแล้ว

96รายการจากแบบเดิมครบ8ชนิด ×6เลเวล(10/20/40/60/80/100) ×ขาว/ฟ้า ข้อมูลruntimeอยู่shared/items.ts มีชื่อ ภาพ ค่าพลัง เงื่อนไขและinstanceIDจริงในกระเป๋า25ช่อง พร้อมช่องอาวุธหลักและโล่ ใช้ATK/MATK/DEFตามชนิด ไม่หมดอายุเมื่อเลเวลสูงขึ้น

- เงื่อนไขหลักceil(8+0.35×เลเวลอาวุธ) STRสำหรับดาบ/ค้อน,INTสำหรับไม้เท้า/คทา,DEXสำหรับธนู/มีดสั้น,VITสำหรับโล่ มีดสั้นต้องAGIเพิ่มceil(4+0.12×เลเวล) ใช้ค่าสเตตัสพื้นฐานรวมโบนัสเผ่า ไม่ใช้พลังของอาวุธช่วยให้ใส่ตัวเองได้ ทุกเผ่าใช้กติกาเดียวกัน
- ค่าพลังพื้นฐานround(8+1.2×เลเวลอาวุธ) ฟ้า×1.12 เป็นค่าอาวุธ ไม่ใช่เพิ่มดาเมจรวมทั้งตัว12% โล่เพิ่มDEF30%ของค่าพลังโล่ ดาบ/ค้อนรวมโล่ใช้profileที่มีอยู่ อาวุธสองมือถอดโล่อัตโนมัติ สลับของไม่ล้างคูลดาวน์
- ขาวมีโอกาส12%จากมอนสเตอร์ธรรมดาLv.10ขึ้นไป เลือกtierสูงสุดไม่เกินเลเวลมอนสเตอร์แล้วสุ่มหนึ่งใน8ชนิด เข้ากระเป๋าผู้ได้สิทธิ์โดยตรง ถ้ากระเป๋าเต็มจะไม่รับดรอปทั่วไปเพิ่ม
- **ฟ้ามีภาพ/พลัง/การสวมใส่แล้ว แต่ระบบคราฟของผู้เล่นยังไม่เปิด** ไม่ให้NPCคราฟแทนช่าง ในรอบนี้GMรับเพื่อทดสอบจากคลังได้และติดtag GM TEST ทอง/แดงยังแยกระบบตามแผนเดิม
- คลิก **อาวุธ → คลังอาวุธขาว–ฟ้า** เพื่อดู96รายการ กดBสวมไอเทมที่มี สำหรับGMมีปุ่มตั้งLv.100/รีเซ็ตสเตตัส45เพื่อทดสอบทุกชนิด ปุ่มนี้รีเซ็ตEXPและจัดแต้มใหม่ ต่างจากหน้าแต่งตัวที่คงความคืบหน้า ปุ่มล้างอาวุธทดสอบลบเฉพาะไอเทมGM TEST

ภาพที่ถือเป็นspriteอาวุธจริง มีจุดยึดด้ามจับใต้ภาพถุงมือ ท่าสองมือจัดปลายแขนเข้าหาด้ามเดียวกัน ธนูแยกมือจับคันกับมือดึงสาย โล่อยู่มือรอง คงภาพอาวุธตอนเริ่มโจมตีไว้ในmotionเพื่อให้การสลับของกลางง้างไม่ทำให้ภาพกับเอฟเฟคคนละชนิด ยังใช้rigขยับข้อต่อจากภาพตัวละครหน้า/หลัง ไม่ใช่แอนิเมชั่นวาดทุกเฟรมใหม่

## ประชากรมอนสเตอร์และEXP

มีมอนสเตอร์ธรรมดา506ตัวใน21แมพผจญภัย:ทุ่งชุมนุมกลาง18,Field1แมพละ20,Field2แมพละ24,Field3และRedZoneแมพละ28 บอสประจำห้องและรอบWorldBossเดิมแยกจากจำนวนนี้ เมืองทั้ง7แห่งไม่เกิดมอนสเตอร์

เลือกเฉพาะจุดเดินถึงได้ กระจายด้วยระยะห่างจากจุดที่เลือกแล้ว เว้นระยะเกิดอย่างน้อย2ช่อง และห่างประตู/จุดเกิดผู้เล่นเกิน3ช่อง เก็บสายพันธุ์เดิมครบ118ระดับ แต่เพิ่มหลายตัวต่อสายพันธุ์และมีตัวLv.1ใกล้ทางเข้าField1 พื้นที่ป่า/หิมะ/บึงยังใช้มอนสเตอร์ตามภูมิภาคเดิม

เกิดใหม่หลัง18วินาทีที่ตำแหน่งเดิม ถ้ามีผู้เล่นมีชีวิตยืนใกล้จุดนั้น2.5ช่องจะเลื่อนไปอีก1วินาที ป้องกันเกิดทับผู้เล่น การเดินไล่/ลาดตระเวนอาจทำให้มอนสเตอร์เข้าใกล้กันระหว่างเล่นได้ ไม่ใช่ระบบcollisionระหว่างมอนสเตอร์

ชื่อเปรียบเทียบกับผู้เล่นแต่ละคน:ต่ำกว่า1–9เลเวลเป็นเขียว,เท่ากันเหลือง,สูงกว่าแดง,ต่ำกว่าตั้งแต่10เลเวลขึ้นไปขาว **ขาวไม่ได้EXP** เกณฑ์ผู้ทำดาเมจสะสมรายบุคคลสูงสุดเดิมยังใช้ แม้ผู้ชนะไม่ได้EXPก็ไม่โอนให้คนอื่น บอสยังไม่ให้EXPตามกติกาเดิม ส่วนเงิน/ไอเทมเป็นรางวัลแยก

## Eira และรากอิกดราซิล

Eiraเป็นNPCหญิงวัยผู้ใหญ่ผมน้ำตาลที่(33.7,36.1)รอบน้ำพุ ชุดใหม่ครีม/เขียวเข้ม/ทองเข้ารูปอย่างสุภาพ มี4เฟรมยืน หายใจ กระพริบตาและผายมือ วนท่าแบบเบาๆ คลิกเดินไปคุยได้จริง มี4บทแนะนำการเล่น พักฟื้น สีชื่อ/EXP และอาวุธ/หอผนึก

รอบหอผนึกรากโลกเปลี่ยนเป็นดินแนวขอบอินทรีย์ ใช้textureรากแตกแขนง เปลือกไม้ มอส ดินดันและรากฝอย เมื่อรากล้ำบนพื้นปูนมีรอยแตก/ก้อนปูนยกตัว ฝั่งดินมีร่องและก้อนดิน เป็นรายละเอียดพื้นซึ่งไม่ปิดทางเข้าหอหรือเปลี่ยนcollisionเดิม
