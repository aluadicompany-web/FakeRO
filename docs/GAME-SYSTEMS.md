# แผนระบบหลักของเกม · ฉบับรวบรวมข้อกำหนด

สถานะ: **แผนออกแบบทั้งเกม** ไม่ใช่รายการระบบที่ทำงานแล้วในต้นแบบ กติกาล่าสุดในเอกสารนี้มีลำดับเหนือคำแนะนำเก่าที่ขัดกัน ตัวเลขสูตรก่อนหน้าเป็นแบบทดลองจนกว่าจะออกแบบส่วนที่เกี่ยวข้องครบ ไม่เผยแพร่หรือเปลี่ยน runtime ในรอบรวบรวมนี้


สถานะโลกที่เล่นได้ล่าสุดแยกไว้ใน [world/RUNTIME.md](world/RUNTIME.md) และผลทดสอบใน [world/RUNTIME-VALIDATION.md](world/RUNTIME-VALIDATION.md) เพื่อไม่สับสนระหว่างแผนทั้งเกมกับส่วนที่สร้างแล้ว

## เป้าหมายและวงจรหลัก

MMORPG คลิกเดิน/โจมตี เว็บคอมพิวเตอร์ก่อน เตรียมมือถือภายหลัง ทดสอบแรกไม่เกิน10คน ไม่มีงบเช่าserver รูปแบบความยากคลาสสิกสูง เป้าหมายระยะยาวคือผู้เล่นพัฒนาตัวเองทุกวันเพื่อพิชิต Main Quest

ตัวละคร/การเติบโต → ต่อสู้/สกิล → ปาร์ตี้/มอนสเตอร์ → เควส/ความเสี่ยงตาย → อุปกรณ์/เศรษฐกิจ → สังคม/การเมือง → เตรียมปาร์ตี้พิชิต Main Quest → เป้าหมายพัฒนารอบใหม่

การพัฒนารายวันเป็นเป้าหมายประสบการณ์เล่น ยังไม่ได้ยืนยันระบบ daily quest, daily cap หรือ login reward

## 1. บัญชี ตัวละคร และขั้นการเติบโต

**ยืนยัน:** เริ่มต้น1ตัวละครต่อบัญชี ออกแบบให้ขยายเป็น4ตัวต่อบัญชีภายหลัง ไม่ใช่สร้างครบ4ตั้งแต่เริ่ม ต้องแยก account_id, character_id และสิทธิ์ผู้ดูแล คนเดิมเปลี่ยนชื่อ/ทรงผม/สีตา/สีผมผ่านไอเท็มตามระบบโดยไม่เปลี่ยน character_id

เผ่ามนุษย์6สาย: Muspelborn แดง/STR, Ljosalfar เขียว/DEX, Jotunborn ฟ้า/VITแนวสนับสนุน, Vanirkin ม่วง/INT, Nidavellir ทอง/LUK, Skuggar ดำ/AGI เผ่าอ้างบทบาท RO แต่ไม่ล็อกอาวุธ ผู้เล่นลงทุนสเตตัสเพื่อเล่นข้ามสายได้

**โครงที่ผู้ใช้ให้:** Lv.1–10ฝึกหัด,20–50 Class1,50–70 Class2,70–90 Class3,90–100+ช่วงสูง ยังไม่ตั้งชื่อคลาสทางการ ขอบเขตLv.11–19,จุดทับ50/70/90และcapสุดท้ายยังไม่ยืนยัน ช่วงแบบ20–49/50–69/70–89ที่เคยเสนอไม่ถือว่าได้รับอนุมัติโดยอัตโนมัติ

**เหลือตัดสินระดับภาพรวม:** วิธีเลื่อนคลาส,เลเวลสูงสุด,การresetสเตตัส/สายเลือด,การย้ายเผ่าและผลต่อการเมือง ไม่ล็อกสูตรโบนัส+1/levelเพราะเป็นเพียงตัวอย่าง

## 2. การต่อสู้และสกิล

ยืนยัน: คลิกเดิน/โจมตี สลับอาวุธฟรีได้ต่อเนื่อง คูลดาวน์สกิลไม่reset สกิลที่ผูกอาวุธระบุเงื่อนไขเป็นรายสกิล ทุกเผ่าใช้เกณฑ์สวมใส่เดียวกัน โบนัสจากอาวุธชิ้นนั้นไม่ช่วยให้ใส่ตัวเองได้

**เหลือตัดสิน:** HP/MPและทรัพยากร,ธาตุ,accuracy/evasion/block/crit,สถานะและการต้าน,สกิลของแต่ละขั้นคลาส/เผ่า/อาวุธ,กติกาPvEกับPvPและเพดานสเตตัส ความชำนาญแยกชนิดและรักษาความคืบหน้าเมื่อเปลี่ยนสายเป็นทิศทางที่ตกลง ส่วนสูตรเวลาใน `systems/WEAPON-RULES.md` เป็นข้อเสนอทดลอง

## 3. มอนสเตอร์ บอส และสิทธิ์รางวัล

### มอนสเตอร์ทั่วไป

ยืนยัน: หากไม่อยู่ปาร์ตี้เดียวกัน ผู้เล่นที่ทำดาเมจมากที่สุดได้สิทธิ์ EXP ทั้งหมด ไม่ใช่ผู้ลาสช็อต หากเป็นปาร์ตี้ให้หาร EXP เท่ากันทุกคน แม้ไม่มีส่วนร่วม ไม่เพิ่มเงื่อนไขว่าต้องทำดาเมจหรือhealขั้นต่ำโดยขัดกับคำสั่งนี้

**ยืนยันเมื่อหลายปาร์ตี้แข่งกัน:** ตัดสินจากดาเมจสะสมรายบุคคล ผู้เล่นที่ทำมากที่สุดได้สิทธิ์EXP ถ้าอยู่ปาร์ตี้จึงหารEXPเท่ากันทั้งปาร์ตี้ของคนนั้น ไม่รวมดาเมจสมาชิกเป็นยอดปาร์ตี้เพื่อแข่งสิทธิ์

ตัวอย่าง: Aทำ400ดาเมจอยู่คนเดียว; BและCทำคนละ300อยู่ปาร์ตี้เดียวกัน แม้ปาร์ตี้B+Cรวม600 ผู้ชนะคือAและรับEXPทั้งหมด หากAมีปาร์ตี้ให้หารแก่สมาชิกปาร์ตี้Aแทน กติกานี้ไม่ใช้กับบอสซึ่งไม่ให้EXP

ยังต้องระบุเพิ่มเติมว่าคนละแมพ/นอกระยะ/ตาย/offline/ต่างเลเวลยังเข้าตัวหารและรับEXPไหม,ปาร์ตี้เปลี่ยนสมาชิกระหว่างสู้,ดาเมจเสมอ,สัตว์อัญเชิญ/DoT/สะท้อนนับให้ใคร และสิทธิ์เก็บของของมอนปกติ

### บอส

ยืนยัน: บอสไม่ให้EXPจากการปราบ ให้โอกาสสุ่มดรอปไอเท็มแทน ไม่ใช้กฎผู้ดาเมจสูงสุดได้EXPกับบอส

บอสแมพ: ทองสุ่มดรอป และมีวัตถุดิบสำหรับคราฟแดงตามสูตร

Main Quest: ข้อกำหนดเดิมให้ปาร์ตี้รับรางวัลอย่างเท่าเทียมและการันตีแรร์ ต้องรักษาไว้แยกจากคำว่าโอกาสสุ่มของบอสทั่วไป อาจสุ่มชนิด/รายการแรร์โดยยังได้แรร์แน่นอน แต่รูปแบบว่าจะเป็นของสำเร็จ วัสดุ หรือโทเคนยังต้องกำหนด ไม่ตีความว่าบอสMain Questกลายเป็นไม่การันตีแล้ว

**เหลือตัดสิน:** จำนวน/สิทธิ์ผู้ลุ้นดรอป,ห้องบอสแยกหรือร่วม,ทีมที่แข่งกัน,ผู้หลุด,การทำซ้ำและรอบรางวัล,AI/threat/respawn/leash กรณีบอสไม่ให้EXPไม่ได้ตัดสินโดยอัตโนมัติว่าเควสที่เกี่ยวข้องจะให้EXPหรือไม่

## 4. ปาร์ตี้

ยืนยัน: ข้ามเผ่าได้ เป็นเพื่อน/ร่วมมือกันได้ EXPที่ปาร์ตี้มีสิทธิ์รับแบ่งเท่ากันไม่วัดส่วนร่วม ไม่บังคับเผ่าเดียวกัน

**เหลือตัดสิน:** จำนวนสมาชิก,หัวหน้าปาร์ตี้,การเชิญ/เตะระหว่างบอส,หน้าต่างloot,การเข้าห้องบอสช้า,กรณีdisconnect/สมาชิกตาย/การแบ่งEXPเศษที่หารไม่ลงตัว และeligibilityด้านพื้นที่ดังข้อ3 ไม่เพิ่มanti-leechขั้นต่ำเอง

## 5. โลก เมือง และเควส

ข้อเสนอผังโลก/อาคาร/เขตบอสฉบับแรกดู [world/README.md](world/README.md) ชื่อและตำแหน่งที่เพิ่มใหม่ยังเป็นข้อเสนอ ไม่ใช่ข้อกำหนดที่ผู้ใช้ยืนยันแล้ว

ยืนยัน: โลกแบ่งเมือง/แมพคล้ายRO มีเมืองประจำเผ่า6เมืองและเมืองหลวง **Central** ใจกลางCentralมีห้อง/หอคอยบอสคลุมด้วยรากอิกดราซิล เป็นMain Questหลักที่ยากมาก

- Main Quest: ความคืบหน้าระดับ **ทั้งเซิร์ฟเวอร์** ต้องแยกจากบันทึกว่าตัวละครใดเข้าร่วม/มีสิทธิ์รับรางวัล/เข้าเนื้อหา
- เควสเผ่า: ความคืบหน้าของ **เผ่า** เผ่าทำหน้าที่องค์กรคล้ายกิลด์ในRO ไม่ใช่เควสส่วนตัวตามเผ่าอย่างเดียว
- เผ่าของผู้ลาสช็อตบอสสุดท้ายได้สิทธิ์พิเศษหนึ่งอย่าง รายละเอียด/อายุสิทธิ์/รอบแข่งขันยังไม่กำหนด คงการเมืองเรื่องจะช่วยเผ่าอื่นพิชิตหรือไม่
- เควสทั่วไปเป็นแหล่งเงินและการพัฒนา เนื้อหา/การรับซ้ำ/รางวัล/เงื่อนไขเข้าร่วมเควสเซิร์ฟเวอร์ภายหลังยังต้องกำหนด

## 6. การตายและชุบชีวิต

ยืนยัน: มีไอเท็มชุบ ใช้เวลาในการชุบ ปาร์ตี้แพ้บอสทั่วไปสามารถกลับเกิดที่เมืองที่เลือกไว้ และถูกหักEXPในอัตราที่เหมาะสมซึ่งยังไม่ได้กำหนด

**เหลือตัดสิน:** หักEXPฐานใด/เท่าไร/ลดเลเวลหรือไม่,ชุบสำเร็จล้างหรือยังคงโทษ,เวลาร่ายและการถูกขัดจังหวะ,ไอเท็มใช้เมื่อเริ่มหรือสำเร็จ,โทษตายPvP/Red Zone/เมืองเผ่า,ตายในMain Questและบอสresetหรือcheckpoint กติกากลับศาลาโดยไม่เสียEXPในต้นแบบเดิมไม่ใช่กติกาเป้าหมายล่าสุด

## 7. อุปกรณ์

อาวุธ/โล่ตามแค็ตตาล็อกเดิม รุ่นพื้นฐาน10/20/40/60/80/100ขาว–ฟ้า96ชิ้น ทองแบ่งกลุ่มตามขั้นคลาสและมีระดับขั้นต่ำไม่บังคับเลิกใช้ แดงคราฟโดยพ่อค้า/Blacksmithและมีstandard/special-repeatable/unique-onceตามฝีมือ ไม่มีpityยูนีค

**ยืนยันเพิ่ม:** ชุดเกราะ ผ้าคลุม รองเท้า เครื่องประดับ แนวRO อุปกรณ์ปกติมาเป็นเซ็ต **ขาว/ฟ้า/ทอง ไม่มีแดง** คอสตูมเพิ่มภายหลัง ไม่ยกกฎอาวุธแดงมาใส่ชุดเกราะ

**เหลือตัดสิน:** ช่องสวมใส่/จำนวนเครื่องประดับ,หมวก/ส่วนหัวจะมีไหม,โบนัสเซ็ต,แหล่งได้/คราฟแต่ละสีของชุด,คุณสมบัติอุปกรณ์ที่ช่วยeligibilityของชิ้นอื่น,ซ่อม/ตีบวก/ย่อย/ความทนทานและเพดาน ไม่นับว่าหมวกและสองช่องเครื่องประดับได้รับอนุมัติเพียงเพราะอ้างRO

## 8. กระเป๋า คลัง และน้ำหนัก

ยืนยัน: กระเป๋าเริ่ม **25ช่อง** เพิ่มด้วยตั๋วเพิ่มช่อง น้ำหนักอิงไอเท็มและSTR

**เหลือตัดสิน:** เพดานช่อง,ตั๋วได้จากไหน/ราคา/เพิ่มครั้งละกี่ช่อง,นับอุปกรณ์สวมใส่ใน25ไหม,stack limit,น้ำหนักเงิน/วัสดุ,คลังส่วนตัวหรือร่วมบัญชี,ภาวะน้ำหนักเกินและขอบเขตที่ทำได้ ตั๋วเพิ่มช่องไม่ได้หมายถึงcash shopได้รับอนุมัติแล้ว

เมื่อคำนวณSTRต้องทดสอบสายเวท/สนับสนุนไม่เสียประสิทธิภาพเดินทางเกินเหตุ แยกความจุช่องกับน้ำหนักเพื่ออธิบายเหตุที่เก็บไม่ได้ให้ชัด แต่ยังไม่ใส่สูตรที่ผู้ใช้ไม่ได้ยืนยัน

## 9. Silfr และเศรษฐกิจ

ยืนยัน: สกุลเงิน **Silfr**, ตัวย่อ **S**, ได้จากเควสและมอนสเตอร์

สินค้าที่NPCมีขาย: ขายคืนNPCได้ **30% ของราคามาตรฐาน** เช่น Red Potion ซื้อ S50 → ขายคืน S15 สินค้าที่NPCไม่ได้ขายใช้ราคาประเมินตามความหายากที่เหมาะสม ไม่ใช่ใช้30%กับราคาตลาดที่ผู้เล่นตั้งเอง

**เหลือตัดสิน:** หน่วยย่อย/การปัดเศษ,สินค้ามีหลายNPCราคาต่างกันจะใช้ฐานไหน,ส่วนลดสกิล/ภาษี,ราคาประเมินnon-NPC,เพดานเงิน,แหล่งเงินออก(ซ่อม/วาร์ป/เช่าร้าน/บริการ) และNPCbuyback ต้องกันกรณีส่วนลดซื้อถูกกว่าราคาขายคืนโดยไม่เปลี่ยนหลัก30%ที่ตกลง

## 10. รวบรวมและผลิต

ยืนยัน: เพิ่มตกปลา ทำอาหาร ขุดแร่ ตัดไม้ และสกิลอื่นที่เหมาะสมได้ เป็นส่วนสนับสนุนการเตรียมพิชิตMain Quest

ข้อเสนอที่เข้าวงจร: สมุนไพร/ปรุงยา เชื่อมอาหารและยากับวัตถุดิบแผนที่ ขุดแร่/ตัดไม้เชื่อมอุปกรณ์ ไม่เพิ่มหลายอาชีพพร้อมกันโดยไร้ประโยชน์ในวงจรหลัก

**เหลือตัดสิน:** ทุกคนฝึกได้กี่สาย,ฝึกขึ้นอย่างไร,เครื่องมือ/จุดรวบรวม/respawn,อาหารกับยาใช้ร่วมกันอย่างไร,คุณภาพ/ผลบัฟ/เวลาคงอยู่,automation/offline และเศรษฐกิจวัตถุดิบ

## 11. ตลาด ร้านค้า และบริการช่าง

ยืนยันก่อนหน้า: ต้องมีสกิลเปิดร้านบริการช่าง เช่าร้านว่างในตลาดหรือใช้แผงลอยเปิดตามจุดที่เลือก ปิดแผงลอยแล้วไอเท็มแผงหาย งานว่าจ้างใช้วัสดุ/เงินescrow ผลรวมยูนีคเป็นของผู้ว่าจ้าง บันทึกชื่อช่าง

ซื้อขายอิสระ ไม่bind โยนของพื้นได้ อายุ30นาทีไม่เก็บหาย ยูนีคหายแล้วห้ามสร้างแบบเดิมอีก ต้องใช้IDและธุรกรรมตาม `systems/WEAPON-RULES.md`

**เหลือตัดสินระดับภาพรวม:** ร้านขายของผู้เล่นใช้ระบบเดียวกับร้านบริการไหม,ตลาดกลาง/ค้นหาสินค้า/ประมูลมีไหม,offline shops,disconnectกับแผงลอย,ปิดร้านมีงานค้าง,ภาษี/ค่าเช่า และของลูกค้าเมื่อเจ้าของร้านลบตัว

## 12. การเดินทาง

ยืนยัน: ต้องไปพื้นที่นั้นมาก่อน จึงวาร์ปไปผ่านNPCได้ ไม่ปลดล็อกทุกจุดตั้งแต่สร้างตัวละคร

**เหลือตัดสิน:** การลงทะเบียนจุดวาร์ป,ค่าใช้จ่าย/รายการNPCปลายทาง,พาเพื่อนไปจุดที่ยังไม่ปลดล็อกได้ไหม,เมืองเกิดและเมืองบันทึก,พื้นที่ห้ามวาร์ป/ออกจากการต่อสู้ และวาร์ปเข้าเมืองเผ่าที่มีความเสี่ยง

## 13. สังคมและเผ่า

ยืนยัน: **ไม่มีกิลด์แยก เผ่าคือองค์กรระดับกิลด์ของเกม** เป็นเพื่อน ปาร์ตี้ และเดินทางข้ามเผ่าได้ ช่วยกันทำเนื้อหาได้ การต่อรองระหว่างเผ่ามีผลกับการลาสบอสสุดท้าย

**เหลือตัดสิน:** แชต/เพื่อน/บล็อก/รายงาน,บทบาทหรือผู้นำเผ่า/สิทธิ์ตัดสินใจ,คลังหรือเป้าหมายร่วมเผ่า,ผู้เล่นเผ่าเดียวกันจะเป็นพันธมิตรPvPทุกพื้นที่ไหม และย้ายเผ่าได้หรือไม่

## 14. PvP และแผนที่

| ประเภทพื้นที่ | กติกาที่ผู้ใช้ยืนยัน |
|---|---|
| Central | ปลอดภัย ห้ามPvP |
| โซนผจญภัยทั่วไป | ปลอดภัย ห้ามPvP |
| Red Zone | เปิดPvP แลกกับมอนสเตอร์EXPสูง |
| ภายในเมืองประจำเผ่า | เจ้าถิ่นโจมตีผู้มาเยือนต่างเผ่าได้ทันทีฝ่ายเดียว ผู้มาเยือนไม่สามารถตอบโต้เจ้าถิ่นได้ แม้ถูกโจมตีก่อน เงื่อนไขนี้เฉพาะภายในเมือง |

คำว่าโซนอื่นปลอดภัยไม่ลบข้อยกเว้นRed Zone/เมืองเผ่า ต้องมีzone ruleบนserverและขอบเขตเมืองชัดเจน ไม่ใช้สีฉากหรือclientเป็นตัวตัดสิน

**ยังต้องตัดสินก่อนimplement:**
- กติกาผู้มาเยือนต่างเผ่าโจมตีกันเองและเจ้าถิ่นโจมตีกันเองยังไม่กำหนด สิทธิ์ที่ยืนยันคือเจ้าถิ่น→ผู้มาเยือนเท่านั้น ไม่เพิ่มสิทธิ์ตอบโต้จากการถูกโจมตีก่อน
- คนเผ่าเดียวกัน/คนในปาร์ตี้โจมตีกันได้ไหม โดยเฉพาะRed Zoneและปาร์ตี้ข้ามเผ่า ไม่ใช้คำว่ามีกิลด์เผ่าแทนคำตอบfriendly fire
- ดาเมจข้ามขอบเขต กระสุน/DoT/AoE การhealคนที่กำลังPvP และการหนีเข้าปลอดภัยใช้กติกาใด
- โทษตาย PvPมีEXPหักหรือของตกไหม? ขณะนี้ยังไม่มีการยืนยันให้ผู้เล่นฆ่าแล้วปล้นของจากกระเป๋าได้
- เส้นทางเริ่มต้น/จุดเกิด/จุดวาร์ปจะหลีกเลี่ยงcampอย่างไร และมอนEXPสูงกว่ากี่เท่า ยังไม่ตั้งตัวเลข

## 15. ผู้ดูแลและความมั่นคงข้อมูล

ยืนยัน: ระบบผู้ดูแลสำหรับเจ้าของเกม (ผู้ใช้) เท่านั้น ไม่เปิดให้ผู้เล่นทั่วไป

ขอบเขตที่ต้องออกแบบ: owner/admin authentication,กำหนดสิทธิ์ฝั่งserver(ไม่ใช่ผู้สมัครคนแรก),ตรวจสถานะworld/player,ประวัติซื้อขาย/คราฟ/ยูนีค,สำรองและกู้ข้อมูล,จัดการรายงาน/โกง/ของซ้ำ,บันทึกการใช้คำสั่งผู้ดูแล ห้ามเครื่องมือadminสร้างยูนีคซ้ำหรือrestoreข้อมูลแค่บางส่วนจนเกิดสำเนา

**เหลือตัดสิน:** วิธีล็อกอินบัญชีจริง/กู้บัญชี,คำสั่งadminที่ต้องการ,วิธีแก้bug/ชดเชย/ban,backup/restore workflow เดิมต้นแบบใช้guest recovery ไม่ได้เท่ากับระบบบัญชี4ตัวหรือowner consoleแล้ว

## 16. ให้บริการและส่วนขยาย

ยืนยัน: เล่นเอง/ทดสอบก่อน ยังไม่กำหนดเวลาเปิด ระบบจ่ายเงินจริงทำหลังทุกอย่างเสถียร ไม่เพิ่มcash shop/ขายตั๋วเพิ่มช่องเงินจริง/แพ็กเกจเงินในรอบนี้

เลื่อนไปภายหลัง: สัตว์เลี้ยง บ้าน สัตว์ขี่ รูเสียบการ์ด และคอสตูม ยังไม่จำเป็นต่อวงจรหลัก

## ระบบที่ยังต้องวางระดับภาพรวมก่อนเจาะสูตร

1. การต่อสู้/ทรัพยากร/สกิลและความแตกต่างของเผ่า/ขั้นคลาส
2. โครงพื้นที่/AIมอนสเตอร์/บอส และการให้สิทธิ์รางวัลเมื่อหลายกลุ่มร่วมสู้
3. ความคืบหน้าMain Questระดับserverและการเข้าเล่นของผู้มาทีหลัง
4. PvPที่เมืองเผ่า/friendly fire/โทษตายและขอบเขตปลอดภัย
5. โครงequipment slots/เซ็ต,คลัง/stack/น้ำหนัก,ช่องทางรับตั๋ว
6. วงจรวัตถุดิบ–ผลิต–ใช้–ย่อย และตลาดขายของนอกเหนือบริการช่าง
7. ขอบเขตบัญชี/admin/ข้อมูลถาวรและการให้บริการ

กติกาที่ตกลงแล้วไม่จำเป็นต้องถามยืนยันซ้ำ รายการเปิดข้างต้นคือข้อมูลที่ยังไม่ได้กำหนด ไม่ใช่รายการให้ผู้ใช้ตอบทั้งหมดในคราวเดียว
