# Central · ยามผนึกอิกดราซิล

การ์ดฝ่ายกลาง 2 คนยืนหน้าประตูหอคอย สวมเครื่องแบบเกราะเงิน ผ้าคลุม/ผ้าทับเกราะแดง และตราต้นไม้ของ Central ทั้งสองใช้แบบเดียวกัน หันดาบเข้าหากันเพื่อกั้นประตู มีภาพ idle/หายใจ/กะพริบตา 4 เฟรมต่อมุม ทั้งหมด 8 เฟรม เป็น NPC สนทนา ไม่ใช่มอนสเตอร์และไม่ให้ EXP หรือของดรอป

## ทางเข้าของผู้เล่น

1. คลิกการ์ดคนใดก็ได้ ผู้เล่นจะเดินมาหน้าประตูตาม pathfinding เดิม
2. เซิร์ฟเวอร์ออกคำยืนยันเฉพาะตัวละคร เมื่ออยู่ใกล้จุดสนทนาและยังมีชีวิต
3. หน้าต่างสนทนาแสดง **ยืนยันเข้าหอคอยอิกดราซิล** และ **ยังไม่เข้า**
4. ยืนยันแล้วจึงย้ายไป `root_trial` โดยใช้คำยืนยันได้ครั้งเดียว

คลิกตัวหอคอยโดยตรงจะบอกให้คุยกับการ์ด ปุ่มในแผนที่โลกเปลี่ยนเป็นเดินไปคุยกับการ์ด การวาร์ปผู้เล่นข้ามไปหอคอยถูกปิดแม้จะเคยค้นพบห้องนี้แล้ว ส่วนเครื่องมือวาร์ปของ GM ยังเป็นคำสั่งผู้ดูแลตามเดิม

ยกเลิก ปิดหน้าต่างด้วย X/Escape เดินออกจากการสนทนา ตาย ย้ายแมพ หรือครบ 30 วินาที จะต้องคุยใหม่ คำยืนยันอยู่ในหน่วยความจำของ actor ไม่บันทึกลงบัญชี และส่งใน snapshot ของเจ้าตัวเท่านั้น อีกตัวละครไม่สามารถใช้แทนได้ ผู้เล่นที่บันทึกอยู่ในหอคอยแล้วสามารถกลับมาเล่นตำแหน่งเดิมได้ตามระบบบันทึกเดิม

## ไฟล์

- `shared/tower.ts`: พิกัดการ์ด จุดสนทนา และอายุคำยืนยัน
- `shared/central.ts`: NPC ในแผนที่ ใช้จุดเข้าถึงเดิมของหอคอย จึงไม่ต้องเปลี่ยน collision/รูปหอคอย
- `server/world.ts`: ออก ตรวจ ยกเลิก และใช้คำยืนยัน
- `client/tower-guards.ts`: ภาพการ์ดในแมพและ idle animation
- `client/world-ui.ts`: หน้าต่างสนทนา/ยืนยันและการยกเลิกเมื่อปิดหน้าต่าง
- `docs/art/tower-guards-source.png`: ภาพวาดต้นฉบับใหม่ ไม่มี sprite จากเกมอื่น
- `scripts/pack-tower-guards.py`: จัดสเกลร่วม/พื้นเท้าและเตรียม WebP โปร่งใส 192×288 ต่อเฟรม

## ตรวจสอบ

`npm run art:tower-guards` ใช้ Python/Pillow/NumPy เตรียมภาพซ้ำ

Build และ unit tests ผ่าน 91/91 รวมการคุยกับการ์ดทั้งสอง ใช้คำยืนยันครั้งเดียว ยกเลิก เดินออกห่าง หมดอายุ ตาย ความเป็นส่วนตัว ข้อมูลของอีกผู้เล่น และการวาร์ปข้ามทางเข้า

`npm run test:tower-guards` ทดสอบด้วยบัญชีผู้เล่นในฐานข้อมูลแยก คลิก sprite การ์ดจริงทั้งสอง ยกเลิก/Escape คลิกหอคอยตรง ปุ่มเส้นทางแผนที่โลก ยืนยันเข้า กลับเมือง และลองวาร์ป/ใช้คำยืนยันเก่า ไม่พบ page error หรือภาพ 404 ภาพหลักฐานอยู่ `artifacts/tower-guards/` ซึ่งไม่รวม Git
